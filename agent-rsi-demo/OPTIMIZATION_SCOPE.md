# Agent 可加入的优化举措与边界

## 你要做的事情

每轮给出一个有具体失败证据的假设，然后实际修改候选 `engine` 源码。允许新增算法和组合决策，不局限于开关或调参；小而可检验的改动比一次改掉整套流程更容易归因。不要把待测效果写成已验证的提升。

## 可探索的方向

| 方向 | 可实现举措 | 必须看什么证据 |
| --- | --- | --- |
| 解析和前处理 | 改善规范化、明确模型分类、保留可见端子映射、处理受支持的输入边界 | 与冻结原网表器件/引脚/网络一致；未知输入应报错 |
| 结构/层级决策 | 差分对、电流镜、级联、串并联和反馈局部关系；父子块归属；布局方向 | 拓扑证据，禁止按图号/器件名字硬编码 |
| 初排与SA | 新候选种子、行列间距、可行移动、无源近邻、结构交换/镜像、温度/重热、多种子 | 实际合法布线的Q，而不只是SA估计 |
| 目标函数 | 拥塞估计、错误引脚朝向、结构错位、配对分离、反馈距离 | 估计量与成图指标分开，固定最终评分不改 |
| 布线 | 优先顺序、树的生长顺序、障碍候选轨道、合法绕行、拆网重布调度 | 全网连通、异网净距、交叉净区、固定出线 |
| 失败恢复 | 定位局部冲突、接口修复、扩距、有限重试和稳健后备 | 原引脚与网表不变，失败必须如实保留 |
| 安全缩线 | 新的短路形状候选、支线重接、内部轨道内收、分支公平轮转、快速预筛 | 提交前完整验收，避免从旧快照覆盖已取得的收益 |
| 展示与画布 | 同一物理图的标签规避、留白、画布范围、可读性诊断 | 不隐藏或删除导线/器件；固定重绘图与候选视觉输出分开记录 |

## 可编辑接口

- 工作区相对于候选根：`engine/candidate_entry.py`、常规生成算法 `engine/*.py`（精确清单由 CodingAgent 提供）与新增 `engine/strategies/*.py`。
- 入口仍接受 `--input --out --seed --iterations --cell`，保存恰好一个 `*-placement.json`、一个 `*-clean.svg` 和一个彩色 SVG。符号保留 `data-component`，线路保留 `data-net` 原生正交 polyline；保留真实符号和供电/分支图元，不能改小透明度或裁掉电路来降低展示代价。
- `engine/routing_rules.py`、`sa_routing.py`、符号和几何资源、冻结 reference、外部验收/评分、数据集、RSI 核心均禁止编辑。可以改寻路算法，但不能削弱规则。
- 不允许把案例名称、验证或测试样例答案、冻结参考结果写进生成逻辑。分析只接收 search 轨迹及离散历史标签；验证/封存集分数不进入 Agent 提案上下文。

## 假设卡范式

例如：“搜索图中多端 `bias` 网外围绕行明显，且第一次连接选择了最远端子。新增按已有连接树最近出口逐步接入的策略，预期降低实际线长；固定连接和异网净距全部保留。”然后在代码中实现该机制，记录修改文件和diff，由本地评测判断是否采用。

## 采用与终点评价

实际使用给定 RSI v4.1：A/A 校准波动、search 诊断、候选实现、search smoke、验证配对、必要复测，最后根据 `Δ > 0 且 Δ ≥ c×SE` 及守护规则采用；当前无额外机制确认，默认 c=1。硬错误通过严格最大值守护：任意一张验证图非法就不能采用；交叉逐图不得增加；线长逐图最大允许增加15%，同时综合Q必须满足统计门槛。几何约束绝不依靠平均分抵消。

v2 在几何Q上加入实际候选SVG的展示惩罚：`2×标签互撞 + 标签碰体 + 0.2×标签碰线 + 2×标签裁切 + 0.05×max(0,画布/电路面积比−2)`。文本框是确定性估计；标签为可见原生text，字号10～24，不能删器件标签。可新增标签避让、合理画布等机制，几何保持时也能因展示改善而被采用；同网线段合并/切段不会改变标签碰线统计。

候选先通过冻结兼容性回归与search smoke；可根据返回的公开堆栈/诊断做有限修复。不得读取验证或封存成绩来修复候选。网络/验收基础设施不可测与电路图不合法分开记录；前者不计零分、不污染测量缓存。

冻结参考采用当前完整 gongzuo 流程。终点报告逐图显示候选是否通过、Q差距、交叉/线长/折角；“达到参考”只针对实际测量的样例及预算。测试集在优化结束后单独测量，不回流给Agent。没有改善或超时也是合法实验结果。
