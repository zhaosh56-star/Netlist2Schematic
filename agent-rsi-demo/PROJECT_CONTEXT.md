# 给 Claude 的项目上下文

## 任务与终点

把原始 SPICE 网表转换为清楚、正确、可复核的模拟电路原理图。RSI 每轮应提出并实现一个新的生成机制：识别问题、修改源码、生成候选、独立验收、与父版本配对比较、采用或拒绝。图形效果要从实际最终线路衡量，不能拿 SA 的估计能量冒充实际成品质量。

目标参考是 `reference/engine` 中冻结的当前 gongzuo 完整流程。`engine` 的算法和资源已配齐，但起跑入口有意采用基础自由网格 SA，关闭结构摆件和安全缩线。可调用现有模块并重组 workflow，也可新增 `engine/strategies/*.py`。复用现有能力是有效举措，后续仍应根据实际证据发现新问题。

## 当前工程如何生成电路图

1. `netlist_core` 处理 UTF-8/BOM、续行、相对 include、model、显式选择 subckt。支持 MOS、BJT、R/C/L/D、V/I、受限的 E 运放代理；不能递归展开任意 X 子电路。保留原网表，不静默丢弃未知器件。
2. `device_leveling` 根据 MOS/BJT 导通关系确定层级；`circuit_structures` / `vf2_match` 等识别差分对、电流镜、级联、负载、反馈及父子结构。
3. 基础版在网格中 SA 移位/交换/改变允许的朝向。当前参考版使用多个结构种子，按 HPWL、估计交叉、折角、结构关系等快速估价；无源器件可采用灵活移动。最终候选要通过真正布线再比较。
4. 使用真实 symbol geometry 将器件中心及朝向映射为引脚世界坐标，冻结器件摆位，建立器件与标记保护区、引脚固定出线及压缩正交搜索图。A* 可以共享同网干线，拆网重布和外围扩展用于处理拥堵。
5. 完整验收检查原始可见引脚、同网连通、异网分离、正交、穿体、保护区、固定引脚出线和电源/地连接。失败可进入局部救援、扩距或总线后备，不能把失败线路直接标为成功。
6. 已经合法的线路再安全缩短：直线/L形、叶支路重接、三段折线、轨道内收及公平调度/预筛。每次替换仍要完整验收。
7. 保存同一份最终线路到 placement JSON、彩色与黑白 SVG。符号来自随包提供的 Analog Canvas definitions；画布是带 viewBox 的真实 SVG，不是抽象方框或外部网页依赖。

## 真实器件与可见连接

符号几何缓存和 110 个 definitions 均随包提供，覆盖流程用到的 MOS/BJT/无源/源/运放代理及电源/地端口。MOS 的 D/G/S 等可见端和符号画法保持原工程约定；体端与 BJT 衬底等隐藏端仍保留在网表中，但不会被虚构成额外可见端。是否支持某输入以冻结解析器实际接受结果为准。

## 完整硬要求

- 原始器件不增不删、不换电气连接；显式选择同一个 cell。
- 每个原始可见信号引脚正确接入所属网络；同网完整连通，无未知网络。
- 线段坐标有限且水平/竖直，器件与符号引脚位置一致，不能穿器件和电源标记保护区。
- 线宽 2.5，异网笔画净距至少 6，对应平行中心距 10；器件 halo 12。
- 合法异网十字交叉必须直穿，离引脚、转角、分支、线端至少 12，不能交叉固定引脚出线。异网共轨、贴线、T接和线端误接均禁止。
- 显式电源连接需正确的标记、接点和引线。完整几何验收通过不等于完成电路功能仿真。

冻结验收进程会重新解析原始输入、使用固定规则检查保存线路，并从同一份合法线路重绘两种 SVG。候选自报的 valid、分数、参数、结构标签不能代替该检查。

## 成品质量

独立评分从实际唯一线路重新计算：

`Q = 线长/100 + 1.5×交叉 + 0.15×折角 + 0.5×超出HPWL线长/100 + 结构错位 + 结构分散`。

Q 越低越好。RSI 主分数为 `100/(100+Q)`，非法图为 0。各图记录真实线长、交叉、折角、绕行、结构对齐和分散；SA 能量仅作诊断。参考能力比较必须使用同一网表及种子，并披露 baseline/candidate/reference 的步数和时间预算。

从v2开始，主分数改为 `100/(100+几何Q+展示惩罚)`，展示惩罚衡量标签互撞/碰体/碰线/裁切和画布留白，公式见 OPTIMIZATION_SCOPE.md。几何Q单独保存为geometry_score。实际候选双SVG必须通过原生符号和线路一致性检查；固定重绘保留为审计副本。旧v1结果不与v2混用。
