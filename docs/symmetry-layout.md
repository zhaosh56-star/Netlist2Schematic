# 器件对称布局实验

核对日期：2026-11-27。`--symmetry-layout off`为默认；显式auto才在结构候选2/3的SA和兼容反馈之后、最终A*之前规整器件位置与方向。导线不要求镜像，也不取消原有基本配对、主列或合法朝向规则。

## 作用与边界

使用有明确拓扑证据的局部配对、多层对应核心、成对无源附件及专属尾部。不同区域可以有不同轴；偏置、启动和单端输出不强补另一半。不能仅因两管共电源、共地或同型号认作对称，镜像参考/输出角色仍保留。

每候选最多两轮、128次试摆、1秒，受对应候选截止时间约束，不调用A*试摆。有源保持原行，使用已有物理行列和合法朝向；成对无源可选择原行或对应行的合法空位。不新增物理轴或逐器件微偏移，无关或固定器件不移动。

动作必须降低对称误差、通过占位和静态几何检查，估计线长相对本次规整前不超过125%。这些是**局部动作接受条件**；后面仍需完整布线验收。

## 指标与最终选择

按真实引脚测左右关于局部轴的偏差，公共尾部量测接点到轴的距离。`failed_relations`计超过网格精度的未满足关系，`residual`为平均误差，`residual_bucket`按网格分档。没有识别到关系时零误差不代表整图完美对称。

**当前最终选图统一使用折角→交叉→信号线长。** 历史“Q参考＋实际线长125%＋对称优先”不再覆盖胜者，只保留为布局偏好诊断。关闭本实验也不是恢复按Q选图；详见[当前选图规则](candidate-selection.md)。

## 运行、保存与历史

```powershell
.\.venv\Scripts\python.exe .\run_flow.py .\examples\3.cir --symmetry-layout auto --out-dir .\output\3-symmetry
```

候选1保留参照；不兼容的region/readability/attachment等实验不能强行叠加。`--passive-layout fixed`只约束原SA，显式对称收尾仍可能移动证据明确的成对无源。保存JSON重布、缩线和独立重绘不自动规整。

`layout_symmetry`保存依据、局部轴、动作、误差、跳过原因和耗时。实现位于 `netlist2schematic/plugins/symmetry/symmetry_layout.py`，旧版实验与发布条件见[对称实验日志](history/symmetry-layout-log.md)。历史指标不等于当前代码重新运行的结果，实验继续默认关闭。
