# 器件对称布局：做什么、怎样运行

这一步可以理解为：SA先摆出一种方案，再在正式布线前，把明确属于左右两侧的器件整理一下。目标是器件位置和方向更对称，导线仍由原来的A*连接，不要求导线镜像。

**当前默认 `--symmetry-layout off`。** 日常命令不加该参数时，跳过额外的器件对称规整和S对称选优，按原Q选择候选。只有显式添加 `--symmetry-layout auto` 才启用下文的规整和对称选优；算法及此前生成的图片保留。

## 能处理的关系

- 差分对、交叉耦合对等有明确拓扑证据的局部配对。
- 多层对应结构围绕共同局部轴展开，各层宽度可以不同。
- 两侧同类型、同接入角色的无源负载或附件跟随对应关系。
- 尾部供给关系明确时，在现有合法空位中尽量居中。
- BJT按C/B/E角色识别具有真实尾部证据的局部配对。

一个大电路可以有多个轴。折叠结构的输入区与输出区可以分别对称；单端输出、偏置和启动附件不必补出另一半。不能因为两只管共VDD、共地或同型号就认作对称。电流镜参考管和输出管的角色也不会被抹平。

已经识别出的独立核心及其尾部是扩展边界，不能只因一根控制线相连就把两级差分或共模反馈区拉到同一轴。每向外扩展一层，先收集全部候选，再排除配对或端口映射有歧义的关系；不会按网名先到先得。整层超过16个器件的容量时停止该层，避免改名后因截断顺序不同而得到另一套配对。

本轮暂不增加“上下串接管的导通引脚同轴”的目标，不增加逐器件坐标微偏移。器件只能使用已有物理行列上的合法位置；网格不允许完全对称时保留残差。

## 执行顺序

显式开启 `--symmetry-layout auto` 后，执行顺序如下；默认 `off` 跳过其中的器件对称规整，并按原Q直接选优。

```text
原初排与SA
→ 原朝向修正、几何间距检查
→ 候选3可能的原布线反馈替换
→ 候选2/3的器件对称规整
→ 捕获实际失败候选与安全现场
→ 原最终A*和完整验收
→ 原Q参考、实际线长125%筛选、器件对称选优
→ 必要时原恢复链
→ 原v5导线简化
→ JSON与两种SVG
```

候选1保留原摆法，提供本轮参照。候选2、3各最多两轮、128个试摆、1秒，计入原300秒预算；不增加候选或最终A*次数，也不在试摆中调用SA/A*。前面的候选耗尽预算时，后面的规整可能没有执行。

候选3的反馈来源仍按原Q确定，对称只在候选评估结束后决定最终交付哪一份。显式回放编号时返回请求编号，不由对称排序换成另一份。

`--passive-layout fixed` 控制的是原SA中的无源固定行策略；显式开启对称收尾后，拓扑明确配对的无源件仍可能在收尾时调整。当前默认已经关闭对称收尾；若指定了 `auto` 又需要复现原Q流程，可改回 `--symmetry-layout off`。

## 怎样控制改动

每次试摆先检查行列占位、固定器件、合法朝向和结构内部禁插入约束，再重建含器件保护区、固定出线、电源标记的场景进行静态几何检查。只有对称改善、整图估计信号线长不超过该候选规整前125%的动作才可能接受；不满足就完整撤销。

有源器件保持原行。成对无源件可以使用原行或对应件所在行的合法空位；无关器件不随意挪动。原锁存时钟访问修正继续有效。物理轴不变化，器件图形、halo和布线间距不缩放。

这些静态检查不是整图已接通的证明。仍须完成原A*和完整连接、几何验收，才能成为成功候选。

## 实际线长125%是什么意思

仅在显式开启 `--symmetry-layout auto` 时，最终候选选择分两步；默认 `off` 直接使用原Q：

1. 从本轮完成完整验收的候选中，按原Q找到参考结果，记下其实际信号线长。
2. 在实际线长不超过参考125%的候选中，先比较高置信对称关系满足情况，再比较按网格精度分档的位置残差；对称程度相同时按原Q、交叉、线长和编号稳定择优。

例如本轮参考线长是4000，线长5000仍在范围内，超过5000则不能凭更对称而胜出。这里比较的是本轮已成功候选、最终导线简化前的线路，不是历史SVG、未布线估计或关闭策略另一次运行的结果。

原Q继续统计线长、交叉、折角、绕行、结构对齐和分散。它不被改写成对称分数；合法交叉仍允许存在，同等对称程度下由原Q约束布线质量。末尾v5简化的“线长、交叉、折角不增加”门槛保持原样。

对称测量使用实际引脚：每个配对比较左右对应引脚的 `|左x + 右x - 2×轴x| + |左y - 右y|`，先在该器件对的引脚间取平均；公共尾部比较真实接点到轴的水平距离。`failed_relations` 是误差超过一个 `grid_step` 的关系数量，`residual` 是关系误差的均值，`residual_bucket` 按 `grid_step` 向上分档。先比较未满足关系数量，再比较残差档位；试摆同档时还比较原始残差。它们与原Q分别记录，不要求每一个局部关系都同时改善。

`relation_count=0` 表示没有识别出本轮能够处理的对称关系，此时显示的零残差不表示整张图已经完全对称，算法会保留原选优方式。

## 命令

在项目根目录的PowerShell中运行，输出到独立目录：

```powershell
# 日常默认：不加对称参数，跳过规整和S选优，按原Q选择
.\.venv\Scripts\python.exe .\run_flow.py .\examples\3.cir --out-dir .\output\3-symmetry-off

# 显式开启：候选1保留原摆法，2/3尝试器件对称规整
.\.venv\Scripts\python.exe .\run_flow.py .\examples\3.cir --symmetry-layout auto --out-dir .\output\3-symmetry

# 指定候选2，验证规整；失败时不自动换候选
.\.venv\Scripts\python.exe .\run_flow.py .\examples\3.cir --candidate-id 2 --symmetry-layout auto --out-dir .\output\3-symmetry-candidate2

# 数据集和图1～7的完整对照，默认每张正常预算300秒，支持同签名断点复用
.\.venv\Scripts\python.exe .\tools\compare_symmetry_layouts.py --jobs 2
```

不加对称参数与显式 `--symmetry-layout off` 等价。对照工具会显式传入 `off`、`auto` 两种模式，入口默认值变化不改变它的实验含义，无需因此重跑已有对照。对照入口为 `output/symmetry-comparison/index.html`，机器记录为同目录 `comparison.json`。工具保留ground truth视觉参考、两组结果、独立标轴预览、各阶段耗时和实际参数。输入、递归include、源码和符号哈希不同不会复用旧结果。

完整flow受真实时间截止控制，并发负载可能改变SA实际完成步数和后续候选覆盖。比较时应同时查看候选及停止记录；即使输入和种子相同，也不能把预算截断下的每一项差值都归为对称规整本身的净收益。

数据集有25份网表，具体可运行数量按本次输入快照预检。空文件、孤立`.ends`和当前不支持的通用X实例都会明确记录，工具不修改原网表，也不把参考SVG当作已通过本项目验收的线路。输入在运行期间变化会使该次对照失效，不能把不同版本的auto/off结果拿来计算改善。

## JSON怎样看

- `requested_symmetry_layout`：入口请求的策略。
- `layout_symmetry`：显式开启时的识别关系、局部轴、规整前后及当前误差、实际动作、跳过原因和耗时；默认新布局通常不生成此字段。
- `quality.score`：原Q；末尾简化后按最终线路更新。
- `quality.selection_policy`：候选选择策略，或者显式回放。
- `quality.symmetry_selection`：显式auto正常选优时的本轮参考候选、实际线长上限、可选编号与最终选择依据；记录的是简化前的选择现场。

恢复阶段可能改变物理轴。最终输出重新测量当前器件位置的对称性，规整时的before/after记录仍保留。总线后备不再次执行器件对称规整。125%门槛用于正常成功候选之间的选择；正常候选全失败后，恢复链没有合法的正常参考，不承诺恢复图满足这一相对线长上限。

旧JSON保持兼容。固定布局重布、单独线路简化及独立重绘都不重新摆件；对已有对称记录最多重新测量，不修改保存的位置。两种正式SVG始终使用同一份完整验收后的最终线路。

## 显式auto/off实验结果

以下保留的是工具显式传入 `auto`、`off` 的完整对照实验，不代表当前日常命令默认启用对称。默认改为 `off` 后，这些历史产物和实测记录不变。

2026-11-09，以种子20261029、20000次提案、正常300秒及恢复60/60/60秒、简化5秒运行，实际并发为6。图1～7和25组数据共64条记录：58份成功结果全部通过原始引脚、固定出线、完整几何、双SVG一致及独立重绘验收；另外3份输入的两个模式共6条记录在解析阶段跳过，没有修改源文件。

427项单元测试、660次器件/非电源网改名及行序变换、16次独立进程哈希种子复现均通过。对照的29个有效电路中，9例对称指标改善，20例相同；真正改变选中器件的位置或朝向的也是这9例。两种模式各有23份正常结果、5份局部救援、1份总线后备。
