# 独立运行与批量出图：默认独立候选预算

主flow和本次整批验证都能从终端独立执行，不需要对话助手参与。`run_flow.py`负责一张图，`tools/run_dataset.py`串行处理一个目录，并生成GT／成品的内嵌图片报告。

## 单图默认flow

下面是在当前Windows项目中使用Git Bash的命令：

```bash
cd /d/gongzuo
./.venv/Scripts/python.exe run_flow.py \
  test_data2/image2net-1874-two-stage-miller-op-amp-with-resistor-bias.spi \
  --cell dut
```

默认每张图只调用一次主flow；内部按[独立候选预算](candidate-pipeline.md)执行，**整图外层保护上限720秒**：

```text
候选2：120秒正常运行 → 30秒原候选修复 → 30秒局部救援 → 30秒1.5倍扩距
候选3：同样的独立预算
→ 比较合法结果；两者均失败才给候选1相同预算
→ 候选1仍失败，最终bus最多60秒
→ 合法候选共享安全缩线5秒
→ 自动正式字体、就近标号、安全局部VDD合并及输出
```

某候选成功就跳过自身后续恢复，但候选2成功仍尝试候选3。候选按折角、交叉、线长选图；完成一张立即处理下一张，不等满720秒。阶段上限不随`--time-seconds`缩放；它只是外层保护上限。需要更长正常阶段时同时设置`--quality-seconds`和足够大的整图上限；0可取消外层上限。

正式成品直接在输出目录顶层 `*-formal.svg`；`flow-result.json` 指向本次正式文件及复验记录。原生 `*-placement.json`、`*-clean.svg` 和彩色图照常保留。`--formal-output off` 可仅输出原生版本。

CLI使用父进程守住总时限；超时只停止本次拥有的子进程树，包含Windows虚拟环境启动的子解释器，不会清理其他Python任务。先前成功产物保留，未完成的搜索不会标成成功。Python中直接调用 `run()` 使用同一累计阶段时钟；需要进程级硬上限时使用命令入口。

## 一整个目录，使用主flow默认预算

```bash
./.venv/Scripts/python.exe tools/run_dataset.py test_data2 \
  --out-dir output/test-data2-default-run
```

此命令直接沿用主flow的独立候选预算和720秒外层保护，不增加“60秒失败再重试”的外层逻辑，报告直接展示正式图。每张图只调用一次主flow，内部自动完成布局、恢复、缩线及输出。目录中某张图失败不影响继续处理其他输入，最终退出码会反映是否有未出图的输入。

普通扁平网表不加`--cell`。批量工具发现某文件只定义了一个子电路时，会显式选择该子电路；有多个定义且未指定时报告输入歧义。需要整批选择同名子电路时，可加`--cell dut`。不递归展开子电路，不修改原网表。

## 快速验证模式：每张先60秒，失败再120秒

```bash
./.venv/Scripts/python.exe tools/run_dataset.py test_data2 \
  --budget quick \
  --out-dir output/test-data2-quick-run
```

**只有显式加`--budget quick`才使用这项策略，这是保留的显式验证模式，不属于当前默认运行。**

| 本张图的尝试 | 每候选正常上限 | 原候选修复 | 局部救援 | 扩距 | 总线后备 | 缩线 | 外部进程上限 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 第一次 | 50秒 | 1秒 | 1秒 | 1秒 | 1秒 | 5秒 | 60秒 |
| 第二次 | 90秒 | 5秒 | 10秒 | 5秒 | 5秒 | 5秒 | 120秒 |

第一份普通合法结果完成后直接处理下一张。第一次失败，或者只得到总线后备图，才从同一原网表重新运行第二次。**120秒是第二次尝试的独立上限，两次最坏合计约180秒**，不含批量报告、独立重绘及文件校验的少量开销。

60秒是第一次整图的外层上限，120秒是第二次整图的外层上限，不是每候选的保证时间。短跑仍依次运行独立候选，但较小的外层上限会截断后续阶段或后续候选，不再使用旧40%／80%累计切分。短跑仅用于显式快速验证，不能冒充完整默认预算的结果。

限时模式仍使用主flow原来的算法、布局默认开关和恢复顺序，但预算更短，某些难图可能更早进入恢复、总线或失败，不能冒充未限时默认运行的结果。若第二次仍没有普通合法图，会如实保留已验证的后备图或失败记录，不从历史目录借用成品。

## 输出与安全检查

- `index.html`：GT与本轮图的内嵌SVG对照，点击可放大；记录原生信号线长、交叉、折角和实际阶段。
- `manifest.json`：每份输入的cell、精确命令、各次耗时、最终候选、恢复阶段及源码／输入／符号资源哈希。
- `runs/cXX/`：每次尝试的原始日志、JSON、彩色SVG、黑白SVG和失败诊断。
- 每份成功JSON都重新检查原始引脚连接和几何合法性，并比较彩色、黑白、独立重绘的线路及器件坐标。

总线后备单独标明。默认网标和共享VDD额外视图仍关闭。统计的“信号线长”不含供电引线，GT只作视觉参照，不伪造同口径GT指标。

每次请选择新的`--out-dir`，工具拒绝覆盖已有批次清单。省略该参数时，自动创建带时间戳的输出目录。运行期间不要修改输入、主flow代码和符号资源；完成后会核对哈希。

PowerShell可以使用同样参数，把Python入口写成`.\.venv\Scripts\python.exe`；Linux或macOS使用环境中的`python3`或`.venv/bin/python`。批量工具通过当前Python解释器启动主flow，不需要额外的系统`python`命令。
