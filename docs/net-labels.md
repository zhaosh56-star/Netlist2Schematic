# 可选网标展示：保留局部连线，省去远距离大绕线

网标插件把完整合法原理图中的少量远程连接，改为“局部实体连线＋同名网标”。例如一个网络有七个端子，可以保留左侧三端互联、右侧三端互联和一个独立端子，每个局部组接一个相同网名。它不会把每个端子都单独贴标签。

插件默认关闭，只用于主flow的额外展示。原网表、器件位置、完整线路、`metrics`、`quality.score`和原验收结果保持原含义；网标版可见线长不是A*布线质量。它不修改RSI的冻结参考、验收或评分。

## 接入顺序

```text
原布局与SA → 原A*及必要的恢复 → 完整验收 → 原安全缩线
→ 保存完整导线结果 → 可选网标插件 → 展示验收 → 额外网标JSON和两种SVG
```

必须先有完整合法线路。第一版不能省去A*耗时，也不能用标签救活失败路线。已有结果单独生成网标版时，不执行布局、SA、A*、恢复或缩线。

## 运行命令

```powershell
Set-Location D:\gongzuo

# 从网标JSON独立复验、重绘；不重新选择拆分位置

```

插件输出采用独立指纹目录，包含彩色与黑白网标SVG、网标记录和诊断。完整原图及原JSON不被覆盖。独立重绘使用保存的局部线路、网标接点和短引线；输入或资源指纹变化时明确拒绝，不悄悄重新规划。

两种网标SVG共用固定的clean文字布局、局部线路和标签接点；已有正式端口文字在对应网络改用网标时避免重复显示。原来的彩色/黑白完整导线图保留原显示方式。长网表名会缩短产物文件名并加哈希后缀，完整来源名仍保存在记录里，避免Windows临时目录叠加超过路径限制。

## 什么情况会自动替换

先按当前物理行列的中位间距得到节距`S`；旧网格使用原节距。规范化每网线路，忽略普通共线切段，再提取内部没有真实引脚、固定出线或分支的连续自由路径，包含长直线。

满足以下任一条件才尝试：

- 路径长度至少`6S`。
- 路径长度至少`4S`，且比两端曼哈顿距离多绕至少`1.5S`。
- 路径长度至少`3S`，且经过至少三处异网交叉。

候选按严重程度、绕行余量、长度和坐标稳定排序，不根据图号、器件编号或网名特殊处理。原线路距离不超过`2S`的端子关系保持在同一局部组；每网最多四组。只切真正连接不同局部组的自由路径，不借此删除环路或改写一般布线。

每个局部组使用一个网标，文字为原网名。接点取自保留线路的端点、分支和直线中点；每组最多检查八个接点，短引线尝试四个正交方向的24、36、48单位长度，并按网格取整。短引线和文字都要避让器件、供电标记、其他导线及文字。固定引脚出线、电源连接及标记保持原样。

## 怎样证明连接没有变

完整导线仍用原验收复验。网标版另外检查：

1. 可见线路和短引线继续满足原正交、穿体、间距及交叉净区规则。删除导线会产生新线端，仍须重新检查，不能假定删除天然安全。
2. 每个网标有真实接点，接入正确局部组；网名和内部网络身份一致。
3. 每个局部组包含原始可见端子，没有漏标或悬空标记。
4. 将同名网标作为等价连接后，全部端子的网络分组与源网表完全一致，无异网误接。

只有全部通过、可见线长严格减少且交叉不增加，才接受一次拆分。折角、标签数和省略长度单独记录。无法安全放置的候选会撤销，不降低规则。

默认独立预算五秒、最多64次拆分试案。每次接受后从最新已验收线路重新分析；超时保留当前合法成果。有大绕线不意味着一定能替换：附近可能没有合法网标空间、删除后会制造非法线端、路径含必须保留的端子/分支，或已达到局部组及预算上限。

## 查看对照与实际结果

批量工具读取图1～7的主结果和`output/test-data-flexible/summary.json`里的合法结果；该批次的三份不支持网表单独列为跳过，不进入展示恢复。每次执行使用新的批次目录，不把历史缓存当作本轮新结果。

默认入口为`output/net-label-comparison/index.html`，每图并列显示原完整导线、网标版及可用GT，列出完整/可见线长、交叉、折角、标签数、局部组真实端子、停止原因和日志。GT只是视觉参考，不是同一几何规则下的数值最优解。

`comparison.json`和`source-list.json`保留实际输入、源码及资源哈希。执行时禁止调用SA、A*、恢复和缩线，并核对原文件哈希、完整快照不变、双SVG使用相同线路和独立重绘一致性。实际收益及失败以本次生成的记录为准；本说明不预先承诺每张图都会减少长线或变得更美观。
