# 候选独立运行与恢复预算

2026-11-24起，普通新网表的默认结构化、flexible、有源骨架流程使用独立候选预算，不再按整图120秒的40%／80%切分候选。

```text
候选2：正常布局、SA、插入、A*（最多120秒）
       → 原候选修复（额外最多30秒）
       → 局部救援（额外最多30秒）
       → 1.5倍扩距重试（额外最多30秒）
候选3：重复上述独立过程
       → 比较全部合法结果：折角少 → 交叉少 → 信号线长短
两者都没有合法结果：候选1按相同120＋30＋30＋30秒执行
候选1仍失败：最终bus后备，最多60秒
       → 安全缩线、正式出图及保存
```

每个候选一旦成功，就跳过它自己的后续恢复；候选2成功也仍会尝试候选3。候选1和bus只在前面的候选全部失败后运行。不会读取历史成品，不会混用两个候选的布局或失败现场。

## 时间的含义

| 参数 | 当前默认 | 含义 |
| --- | ---: | --- |
| `--quality-seconds` | 120 | 每个候选的正常布局、SA、附件插入、预检和最终A*的共同上限 |
| `--repair-seconds` | 30 | 该候选自己的检查点续插、局部修复及必要的小幅扩距，不重新运行SA |
| `--rescue-seconds` | 30 | 该候选自己的局部接口、阻挡网和模块通道救援 |
| `--spacing-seconds` | 30 | 该候选自己的整图扩距重布一次；倍率默认1.5 |
| `--fallback-seconds` | 60 | 候选1也失败后，最终一次bus构造及验收 |
| `--simplify-seconds` | 5 | 合法候选选图前共享的安全缩线预算，总候选上限仍为512 |
| `--time-seconds` | 720 | 整张图及其CLI子进程树的外层保护上限；0取消这个外层上限 |

一个候选最多210秒，候选2、3最多420秒；候选1也全部用满时，三个候选最多630秒，再加最终bus最多60秒。外层720秒还为解析、缩线和正式输出留出余量。各阶段是上限，完成或确定本次尝试失败就立即进入下一步，不等待时间用满。缺少可恢复现场时明确记录跳过。

阶段预算不随整图上限自动缩放。如果显式设置较小的`--time-seconds`，例如120，外层上限仍会截断后续阶段；这不再是默认运行方式。提高阶段时间时，也应提高外层上限，或明确用0取消外层上限。

## 不变的算法和安全要求

电流分层、主列和子结构保护、无源模块插入、SA动作、A*代价及几何规则不变。SA期间不调用A*。本次调整改变运行调度和失败时的预算，不把未验收的结果列为合法候选。

正常、修复、局部救援和扩距得到的合法结果，先共享原安全缩线预算，再用最终真实线路指标选图。正式输出复验所选线路，不另给胜者重做一次缩线。原质量分Q保留作诊断和布局估价，不覆盖折角、交叉、线长排序；主列结构保护继续有效。

候选1使用原候选1算法，未强制改为无源骨架。它的失败现场也支持相同的恢复顺序。bus是最后独立的构造算法，会改变布局，仍须通过完整连接和几何验收。

解析、资源、损坏输入和源文件变化错误直接失败，不进入恢复。显式`--fallback off`禁用候选1、扩距和bus；局部救援仍按`--local-rescue`策略处理。已有JSON的重布、单独缩线、重绘，以及baseline／legacy和其他显式布局实验不套用本次默认候选调度。

## 运行与查看

```powershell
# 当前默认，不需要再手工指定120/30/30/30
.\.venv\Scripts\python.exe .\run_flow.py .\examples\7.cir

# 批量目录沿用同一默认策略，完成一张立即进入下一张
.\.venv\Scripts\python.exe .\tools\run_dataset.py .\test_data2 --out-dir .\output\test-data2-new

# 单独回放一个候选，保留原显式回放含义
.\.venv\Scripts\python.exe .\run_flow.py .\examples\7.cir --candidate-id 2
```

最终JSON的`candidate_pipeline`保存每个候选、每个阶段的请求时间、实际分配时间、实际耗时、失败原因和最终选择。`recovery.stages`也带有`candidate_id`；`time_budget`记录外层保护预算。原网表、历史JSON和已有成功图不作为本次生成输入，也不会被失败输出覆盖。

实现入口为`netlist2schematic/flow/candidate_pipeline.py`；`run_flow.py`调用它，原候选修复复用`recovery/primary_recovery.py`。单候选失败现场通过私有运行上下文传递，运行对象不进入JSON。
