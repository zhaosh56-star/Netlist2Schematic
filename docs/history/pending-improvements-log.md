## 1. MOS朝向：用结构偏好生成候选，再检查真实布线

### 已确认的问题

当前MOS允许正常或左右镜像。初排倾向让G极朝向同网端子，SA可单管翻转、整组镜像；位置规整后，缺少一次面向真实导线的朝向优化。

SA的交叉估计主要检查跨同一对行的连接是否左右反序，漏掉同层水平偏置线与跨层输入线的交叉。仅改变朝向而保持行列时，这项交叉估计不变。

在c36中，`Vin+`、`Vin−`两条纵向线穿过`Vb3`、`Vb4`两条横向偏置线，实际4次交叉，SA估计却是0。保持D/S真实接点后，朝内和朝外的相关估价均为线长1900、交叉0、折角14，无法体现实际收益。

### 已验证的只读试验

指标为最终信号线长／交叉／折角。试验没有修改默认代码，指定器件来自用户举例，不是生产算法中的特例。

| 样例与操作 | 原成品 | 独立试验 | 结论 |
| --- | --- | --- | --- |
| c36：M2、M3、M8、M9的G朝外 | 2170 / 4 / 5 | 2130 / 0 / 5 | 四管联动有明确收益 |
| c26：仅M5的G朝左 | 2442 / 3 / 18 | 2798 / 2 / 18 | 少一次交叉，但绕线变长，不宜只按朝向强制采用 |
| c26：仅M6的G朝左 | 2442 / 3 / 18 | 2246 / 2 / 14 | M5、M6的同网G相向，三项均改善 |
| c26：M5、M6同时镜像 | 2442 / 3 / 18 | 2438 / 3 / 18 | 整组翻转不必然优于单管调整 |

c26剩余两处交叉属于`Vb5`与`X/Y`，并非都由M5或M6朝向造成。

### 建议改法，尚待实施

- [ ] 独立做朝向收尾插件，首轮保留现有SA，避免同时修改动作、评分和最终路由，难以归因。
- [ ] 仅对已有可信结构或对应主列中的同层配对生成偏好：同G网优先相向，独立输入优先朝外。交叉耦合／锁存按对侧D到G的反馈角色处理；共同偏置、VDD/GND或CLK本身不能建立配对。
- [ ] 支持重复控制网的联动组。c36的上下两组差分对具有相同的两个输入网及一致的支路对应，需要联合尝试四管朝外；不能只做单管翻转，也不能通过公共控制网合并成巨大刚体。
- [ ] 根据符号几何围绕真实D/S轴镜像，用现有水平偏移`dx`补偿符号原点。偏移由引脚坐标计算，不写死20；保持D/S接点、逻辑行列、物理轴和主列。超出合法偏移范围时跳过。
- [ ] 保护固定器件、已有锁存时钟访问朝向及结构角色。绑定了无源模块的G端，首版保守跳过，避免打散已经放好的R/L/C附件。

- [ ] 每个试案使用独立副本；完整连接和几何验收通过才提交，失败或超时撤销，不进入新的整图恢复链。
- [ ] 初版建议线长、交叉、折角均不增加，至少一项下降；合格结果仍按当前“折角→交叉→线长”比较。此护栏只针对新插件，暂不改变主候选选图规则。
- [ ] 每张图共用小预算，建议先试5秒、最多16案，优先处理涉及交叉多的控制网；预算与默认启用方式在实施时确定。

## 2. 差分对：在固定显示行之前落实同行关系

### 已确认的问题：c43的M1／M2

输入：`test_data2/image2net-688-ldo-with-cascoded-nmos-input-error-amplifier.spi`，子电路`dut`。

M1、M2被正确识别为高置信差分对，共同S节点为`net0`，尾电流源为I2。但两侧上游支路长度不同：

```text
VDD  → M3 → M1
VBAT → M5 → M4 → M2
```

原电气层级为M1=2、M2=3。默认布局先固定显示行，随后子结构保护因不同行而跳过，记录`different_fixed_rows`；SA只能横向调整，无法补救。

当前成品为候选3、普通布线，指标2080 / 0 / 12；M1在`row=1,col=5`，M2在`row=2,col=2`，空间上确实分开。不是识别缺失，而是已识别的同行关系没有在行计划阶段落实。该问题在C接入之前已经存在。

### 建议改法，尚待实施

- [ ] 在SA初始化、固定有源行之前，消费高置信差分对的同行关系。
- [ ] 以真实导通先后关系为硬约束，协调两侧显示行，允许较短上游支路保留合法间隔；原电气层级数据和网表保持不变。
- [ ] 复用现有行计划的同层兼容与循环检查。配对存在真实先后关系、SCC冲突、固定位置冲突或识别歧义时跳过并说明原因，不强行合层。
- [ ] 同行之后保留两条主列与左右支路身份，保护输入对子块，并引导局部紧凑，避免只把行号改相同，却仍相隔很远。不要把大父结构锁成整个矩形禁区。
- [ ] 协调明确尾源的位置，使其靠近共同S/E节点；共享尾源或归属有歧义时保守处理。
- [ ] 后续主列规整、R/L/C模块插入、候选3反馈及恢复快照都使用兼容的新行计划，不能用旧布局覆盖。
- [ ] 记录原电气层级、新显示行、同行依据、调整及跳过原因；仍不增加SA随机跨行动作。

### 验证范围
