# 区域化布局：先组织功能区，再优化器件位置

> 历史记录（2026-11-27归档）：以下保留各轮当时的策略、预算、测试数量和结论，不作为当前默认值或可直接复现的保证。当前说明见[文档入口](../README.md)、[候选预算](../candidate-pipeline.md)和[选图规则](../candidate-selection.md)。文中的 output 路径是未随 Git 保存的本地证据。

区域布局使用独立实验开关 `--region-layout auto|off`，目前默认关闭。当前 Goal 按配对、分类型统计和视觉收益评估，不再因单张图退步否定整个策略；明显退步、超时、未适用和未执行必须单独报告。改变默认值仍需用户确认。



下方 72 次批跑及其发布门槛属于上一版冻结记录，不能当作当前代码已完成的全量验证。最新的小步改进、短预算限制及未布线预览见本文末尾。



## 它改善什么



原算法主要知道“这几只管子相关”，但不同器件行可以各自排序，结果是上面属于左支路的管子到了下面又偏到右侧。区域计划在 SA 前记录功能区、局部支路、接入端口和附件归属，在各行使用一致的区域顺序。



首轮针对有完整连接证据的时控双支路核心、折叠主级和采样控制区域。识别依据是真实端口拓扑，不使用文件名、实例编号、信号网名或 GT 坐标。共用电源、偏置或时钟不能单独把器件合并成一个区域。



- 真正串联的器件优先对齐真实 D/S 或 C/E 引脚。

- 左右对应支路保持身份，但不同区域允许镜像和采用不同局部轴。

- 折叠、分叉与跨区反馈记录端口联系，不强制同列。

- 无源件仍可 flexible 跨行移动，附件归属采用软评分；大区域不是禁止其他器件进入的刚性矩形。



算法不要求导线镜像。A*、恢复链、网标开关及安全缩线继续沿用原实现。诊断叠加图上的框和虚线只是解释标记，不能当作实际导线。



## 接入和兼容



候选1保留原算法，候选2、3才尝试区域初排和区域动作。未识别到受支持区域时继续原路径。候选3不能用不兼容的旧布局反馈覆盖区域布局。



第一版 `--region-layout auto` 与 `--structure-layout auto`、`--symmetry-layout auto` 互斥。区域策略不会隐式开启旧结构实验或实验对称。固定布局重布、单独缩线及独立重绘不重新规划区域。



`layout_regions` 记录识别证据、归属、接口、覆盖率、初排及实际动作和指标。`applied` 表示新策略参与了布局，不代表最终选中了该候选，也不证明所有未识别支路都已经规整。原 `quality.score` 保留原含义。

## 如何查看结果和判定发布



`output/region-layout-comparison/index.html` 显示 GT／关闭版／开启版。每份结果链接完整 JSON、彩色图及独立区域/支路叠加图。`comparison.json` 保留逐网绕行、区域覆盖和未覆盖器件、实际候选、恢复阶段及耗时；`runs/` 内按案例、种子、策略和输入/代码/参数指纹隔离。



每份成功图独立复验原始引脚、固定出线、同网连通、异网分离和几何规则，并比较两种 SVG 的导线及独立重绘。两个侧依据同一份源网表计划重新测量，不能通过少识别关系获得更低的违规数。



发布门槛检查安全缩线后的最终成品：逐图线长不超过关闭版115%；原零交叉保持零，其余单图最多增加1处；验证集总交叉不增加；不新增失败、错误有源行变动或总线降级。重点样例还需要确认功能区和上下支路在视觉上确实更清楚。



工具不会自动修改默认值，也不会把部分案例的数值通过记作全量发布成功。自动批跑结束时，`default_promotion_approved` 为 false，视觉复核状态为 pending；实际看图之后再单独记录审查结果。本轮已完成7组看图，结论见下文。

## Goal 后续小步：附件跟随端口，保留独立区域通道



当前新增规则只影响显式 `--region-layout auto` 的候选 2、3。候选 1、默认关闭路径、固定布局重布、单独缩线和独立重绘不会自动重新摆件。没有隐式开启 `attachment-layout all`、结构增强或实验对称。



1. **区分独立区域与核心附件。** 两个独立功能区仍预留一列通道；一个叶块只有在全部成员都通过真实 D/C 端接到同一父区域的核心导通端时，才取消额外隔列。共电源、时钟、偏置或失效端口记录不能获得这一资格。StrongARM 零迭代初排由 8 列变成 6 列；有源行及合法朝向规则保留。

2. **无源链寻找真实宿主。** 初排沿可见 R/C/L/D 连接寻找最近的已确认区域端口；在电源处停止，不穿过 V/I 猜归属。多个等距宿主全部保留为锚点，不选名字最小者，也不传递合并成刚体。具有端口证据的附件可使用相邻区域通道中的合法空位；无关附件仍不可占用该保留空间，同一行叶块内部的完整性继续保护。

3. **识别真实电流源供给的折叠输入级。** 专属电流源连接两只输入 MOS 的公共 S 端、另一端接已确认电源时，可作为输入子区的成员。三者之外再有可见端口、多个源、浮动源或电压源时跳过。记录实际 `+`/`-` 端，不伪装成 MOS 的 D 端；有源覆盖率与辅助源数量分别统计。真实电流源接入的内部公共源节点，也不能仅凭两个体端连接被推断成电源轨。data18 的 10 只 MOS 和专属 I1 因此具有输入区、输出堆栈的明确组织关系。

4. **成功路线后的安全压紧。** `region_compaction.py` 只收紧已证明相邻的核心附件空隙。公共物理横轴与已有正交线使用同一个单调变换；符号尺寸、引脚局部坐标、固定出线及电源标记不缩放。每个试案都完整复验；线长必须下降，交叉、折角及区域指标均不得变差。每候选最多 1 秒、12 次试案，受原正常阶段截止时间约束，不调用 SA/A*，不叠加独立恢复预算。失败或超时保留最后合法结果。



执行顺序是区域初排与原 SA → 原朝向和几何间距检查 → 原 A* 和验收 → 可选安全压紧 → 按实际结果重新评分选候选 → 原安全缩线与输出。候选选择记录保留；A* 搜索诊断明确属于压紧前坐标。JSON 保存更新后的公共横轴，因此独立重绘不会把器件和线路错开。
