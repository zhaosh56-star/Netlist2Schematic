## 新增实验：有源骨架优先，局部扩距后嵌入无源

使用 `--passive-skeleton auto|off`，默认 **off**。它实现的是“有源骨架→局部留位→无源自由坐标”，不是上一轮成品之后的5秒试摆。当前默认长列、端口预检和所有几何规则保留；旧 `--passive-embedding auto` 与本实验互斥，避免再次移动已经安排好的附件。

执行顺序：

1. **编译有类型的附件关系。** 唯一无分叉R/L导通链可以给有源显示行提供先后证据；跨支路RC、并联负载和感测网络保留各自两端，电容和感测电阻不会把不同输出合并。原网表、器件端口及电气 `levels` 不变。
2. **先优化有源骨架。** 候选1完整保留原算法；候选2/3的SA先只处理非无源器件。原SA动作、温度和权重继续使用，附件两端作为仅用于布局估价的辅助连接，帮助保留跨区关系；它们不进入实际布线或网表。原长列和串接收尾在无源件尚未占位时执行。
3. **计算实际空间需求。** 按符号尺寸、双方固定出线、halo及通道宽度，必要时扩大相关公共行列间距。同行、同列和支路身份保持；唯一R/L桥允许修正显示顺序。共同供电或型号本身不能产生配对。
4. **整组放入无源。** 串联件沿连接顺序，成对并联组使用一致且左右对应的排列，控制端附件靠近真实G/B端，侧接D/C端的附件横向展开。无源通过已有 `local_offset` 使用细网格局部坐标，不必占据MOS的整行整列。确有唯一控制链证据的接地源可以归位，浮动、共享、固定或归属不明确的源保守跳过。
5. **静态检查后执行原A*。** 相关附件才允许进入对应小块，无关器件不能穿插。成对附件一起提交，不能只摆好一侧。核心收尾与无源试摆共用候选内1秒／128案窗口，不在试摆或SA中调用A*；所有工作计入原正常质量预算，不增加整图候选数。无法合法放入时记录原因，回到原候选生成路径，因此失败尝试可能产生额外布局计算，但不会增加该候选的整图布线次数。
6. **独立选优及输出。** 各合法候选按同一关系清单测量。先满足本轮原Q最佳结果的线长115%、零交叉保持零／其他最多增加1处、折角不增加护栏，再比较主串联轴、成对附件一致性与局部规整。`quality.score`仍是原真实质量分数。最后继续原恢复链、安全缩线及双SVG输出。保存位置重布、单独缩线和独立重绘不重新搭骨架。

## 当前Goal：保留默认有源骨架的独立无源嵌入

本轮新增 [passive_embedding.py](../../netlist2schematic/plugins/passive_embedding/passive_embedding.py) 和 [safe_postroute.py](../../netlist2schematic/plugins/passive_embedding/safe_postroute.py)，使用独立开关 `--passive-embedding auto|off`，默认 `off`。它保留当前默认的 `--column-layout auto` 及原候选选择，先得到完整合法且经过原安全缩线的成品，再尝试无源整理。下文旧的 `--attachment-layout passive|all` 是另一套历史实验，不需要为使用新模块开启它们。

新模块按真实端口编译无分叉串联路径、精确并联组、多条共端路径及单端附件。公共电源不能把无关支路合成一组，控制端接入使内部节点成为真实分叉，闭合或有歧义的纯无源路径保留原布局。归属锚点可以是同一网络上的多个实际端口，不要求只能属于一只MOS。电源、地及符号方向继续使用原始几何。

从原流程选中的同一张成品出发，按真实端点尝试横排、竖排及端口朝向上的有限位置。通过既有 `passive_local_offsets` 表达局部坐标，逻辑格子仍用于保存和状态管理。MOS/BJT及V/I/E等非无源器件的实际位置、行列、朝向和公共轴精确保留；固定器件及无关小结构内部禁止插入。相邻串联器件的间距由两端实际固定出线长度共同决定，避免符号保护区虽然刚好分开，出线端却相互越过而使路由失败。

原SA、候选数量、随机流和原局部收尾额度完全保留。新事务独立使用5秒：先复验原图，再用最多1秒／128案整理无源，只对这一个提案额外调用一次原整图A*；剩余时间内最多再用2秒执行同一安全缩线，仍受5秒总截止时间约束。试摆本身不调用SA或A*。无无源关系时直接返回；总线后备跳过。搜索与验收按截止时间协作退出，文件输出及最终测量另有少量开销。

每次试摆先检查真实器件、固定出线、电源标记和子结构保护。最终仍以完整原始引脚及几何验收通过的实际线路比较：附件组织必须改善，且相对原成品的线长、交叉和折角三项均不增加，才提交。任何回归、失败或超时都交付原位置和原线路，不继续扩大搜索，也不触发新的恢复链。质量分数按最终实际结果重算，原候选记录保留。保存、重布、单独缩线及重绘只恢复坐标，不再次摆件。

## 算法怎样跑

1. **先确定附件属于哪里。** 从原网表的真实端口识别串联、并联、桥接和局部接地支路；`all` 还识别有明确归属的电压源、电流源及其串联附件。共同电源、地或型号本身不能建立归属，存在歧义时保留原摆法并记录原因。
2. **给相关附件找合法挂位。** 以已确认主支路和接入节点为宿主，尝试在其附近或内部插入附件。初始化可以增加必要的显示行列，也可以协调相关局部成员让位；固定器件和有源导通先后仍受约束。附件不能任意插入不相关的有源小结构。
3. **让 SA 在明确范围内继续优化。** 显示轴在初始化后冻结；位置和朝向是唯一可变状态。无源件沿用 `flexible` 跨行能力，有归属的源在 `all` 中获得相应局部自由度，其他源继续原规则。整组与单件提案都要保持成员归属、链路顺序、固定位置和有源层级。
4. **收尾时按真实引脚再检查。** 在共享的 1 秒、128 次局部试摆预算内，整理附件方向和接入位置。器件、固定出线和电源标记仍必须通过静态几何检查，再进入原 A* 和完整验收；试摆与 SA 不调用 A*。
5. **与旧候选一起比较，再缩线输出。** 候选 1 保留原算法；候选 2、3 才使用新策略。最终既看实际布线，也独立测量附件组织及源角色。失败候选不能作为改进成品；原恢复链和安全缩线继续执行。线长、交叉或组织门槛未过，不默认发布新策略。

| 代码 | 职责 |
|---|---|
| `attachment_integration.py` | 建立附件计划和合法挂位，接入初排、SA 状态、软评分与共同预算，测量无源内嵌和组织结果 |
| `attachment_local.py` | 围绕真实接入节点产生有限的局部位置、朝向试案；由上层统一检查并接受 |
| `attachment_sources.py` | 识别源及源串链的真实归属，生成源提案，测量角色、链路顺序和真实引脚距离 |
| `attachment_selection.py` | 按共同关系清单比较候选，保存及恢复挂位测量上下文，重新测量最终坐标 |

## 三种模式如何比较

| 模式 | 本轮作用 |
|---|---|
| `off` | 关闭新附件融入策略，作为本轮基线 |
| `passive` | 仅启用无源附件融入，独立验收第一阶段 |
| `all` | 无源附件与有明确归属的源器件共同参与，独立验收第二阶段 |

三种模式都使用结构化主流程、现有 `flexible` 无源策略及 `strict` 安全缩线；`readability-layout`、`region-layout`、`structure-layout`、`symmetry-layout`、端口预检和网标插件均显式关闭。这样能区分本轮附件布局的收益与之前的缩线、对称等实验。

默认每张图使用种子 `20261029`、20,000 次 SA 迭代、正常阶段 300 秒、局部救援／扩距／总线后备各 60 秒、缩线 5 秒。三侧保持相同并发数，默认同时运行 2 个任务，最多 3 个。并发会影响按墙钟计时的候选是否来得及执行，因此报告同时保存并发数、实际尝试的候选和最终恢复阶段，不将计时差异直接归因于布局算法。

## Goal 首批短迭代：宿主入口侧、成对负载、导通串链和尾源

2026-11-13 起按新的 Goal 推进，美观采用逐例、分类型、多维统计，不再因一张图的成本退步否决整项策略。电气与几何仍逐图硬验收。下面是短预算试验，不替代完整数据集和默认候选选择的验证；上述1194项是旧冻结版本的完整测试记录。

这次浏览了25份GT，总结出的相对组织规则包括：同类负载应围绕各自接入节点成组；真正串接的导通通路应连贯；输入附件应位于真实控制端入口侧；尾源连接公共S/E节点并尽量居中；偏置和辅助区保持自己的角色。电流镜参考/输出角色、跨区反馈与多个局部轴不应被强行改成全图镜像。算法只读取原网表、已确认结构和符号几何，GT只在对照页显示。

四轮实现分别为：

1. **宿主入口侧软评分。** `attachment_access.py`检查实际宿主引脚到附件端子的投影，补齐原来只检查附件朝向的不足。一个明确宿主，或多个同类S/E、D/C端可以量测；共享偏置、混合端口及歧义不会猜成唯一方向。无法量测与不适用单独记录。
2. **成对负载一起留位。** `attachment_pairs.py`仅对已确认的差分/交叉耦合对，以及各自明确、同类型的并联负载组试摆。两侧支路和各自负载联合调整，区间留一列通道。公共VDD/GND本身不建立配对；不是按图号触发。初始化可使用已有轴或必要扩列，SA后只在保存的轴上规整。
3. **R/L导通链真实引脚对齐。** `attachment_conduction.py`复用`branch_alignment._bridge_relations()`再次校验唯一、无分叉的R/L路径。相关有源器件和附件保留显示行，联合换列，并用现有有界`dx`对齐真实引脚。已确认的竖向导通附件不再进入旧的横向桥接模板。串联C、控制端接入、分叉和歧义仍跳过。
4. **尾源居中。** `source_axis_trials()`只在SA后，对已确认的直接尾源微调水平`dx`，以公共S/E真实接点的中点为目标。使用真实相连的正/负端；固定源、非尾源和无法安全居中的情形保守跳过。源器件的偏移不会进入只恢复行列与朝向的SA撤销接口。

执行顺序为：原识别与R/L行计划 → 导通链联合初排 → 成对负载留位 → 其他附件初排 → 原SA → 原朝向/间距检查 → 导通链、成对负载及其他附件收尾 → 尾源局部居中 → 原A*和完整验收 → 原选优、恢复及缩线。所有附件初排和收尾仍共享每候选1秒、128个试案，试摆不调用A*。后续操作从已接受的最新位置继续，静态检查失败则不提交。

新规则仍只由`--attachment-layout passive|all`开启，候选1保留参照；尾源收尾仅属于`all`。默认仍为`off`，没有隐式开启其他结构、区域或对称实验。固定布局重布和重绘不执行新摆件。

顺序保持为：安装已有权限 → 原早期几何归一化（新增源与外部标记检查）→ 原输入／折叠结构初排 → 原附件与源位置初始化 → 原SA及收尾 → 原A*、恢复和安全缩线。安全种子保留原状态、随机流和候选名额；只有存在已管理源时才建立一次轻量场景查询，不运行完整验收或A*来筛查初始标记。

诊断仍写入 `layout_attachments.initialization.initial_rail_clearance`，新增 `source_marker_conflicts_before`，包含实际源、外部标记所属器件、实体冲突和固定出口。动作类型区分 `initial_source_marker_orientation` 与原 `initial_outward_rail_orientation`。其余JSON、CLI和默认开关保持兼容；参考候选1、`off/passive` 的源权限及保存坐标操作不改变。

本轮验证记录保存在 `output/schematic-goal/source-marker-start-v45/`。第118轮的静态旋转探针只作为实现依据，不算本轮完整布线或美观成功。

## 第122轮：最终验收独立检查器件与电源标记形状

发现并复现了一个独立验收缺口：只有导线合法，不能证明器件保护区彼此分离，也不能证明电源标记没有碰到另一只器件。原预检已经检查这些形状，但关闭可选预检、读取旧JSON或独立重绘时，最终线路复验可能漏掉纯形状碰撞。复现用例只由普通电阻、电流源、真实引脚和原几何表构造，不读取GT或按实例名触发。

现将原形状检查提取为 `routing_rules.static_shape_conflicts()`，由预检和 `sa_routing._verify()` 共同调用。原halo、边界接触规则和自身标记接入豁免保持：器件保护区之间不得有正面积重叠，电源／地标记不得侵入其他器件保护区；网络同名不能豁免异属标记。场景保存实际标记对应的器件身份，自定义电源标记也按其记录的真实身份恢复，不靠网络遍历顺序猜归属。

这属于始终执行的硬验收，与 `--attachment-layout` 或 `--port-preflight` 的开关无关；它不会自动移动器件或电源符号，不新增布局动作，不改SA、A*代价、几何数值、恢复预算和实验默认值。保存的旧 `valid=true` 仍须重新检查，碰撞结果明确拒绝；重绘失败时保留已有输出文件。原向器件内折返的默认电源短线检查继续独立执行。

新增10项针对性测试，覆盖真实漏检反例、预检与最终规则一致性、同网异属标记、标记身份顺序、边界与自定义halo、改名重排／平移镜像、超时以及旧JSON重绘拒绝与文件保护。验证记录和新冻结清单位于 `output/schematic-goal/final-shape-guard-v46/`。此前v45的真实布局生成记录保持原版本，复验不冒充重新运行SA或A*。
