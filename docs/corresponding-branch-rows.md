# 对应支路齐层：先确定显示起点，再运行SA

当前默认的structured＋`--passive-skeleton auto`＋`--column-layout auto`，在候选2、3的SA初始化之前增加显示行规划。候选1保留原参照；`--column-layout off`会连同本项规划一起关闭。旧JSON的重布、单独缩线和重绘仍只恢复保存坐标。

它解决的是：局部支路没有直接接VDD时，原分层会从该支路自己的起点开始数，造成短参考支路整体比对应主支路偏高。例如C02的M1应与M2同行；C44的M1/M2应分别与M3/M4同行。

## 识别与接受条件

1. 复用现有主列识别，先确定不重叠的完整导通列。已确认的R/L/C及V/I跨模块显示关系也参与，原电气分层不变。
2. 优先保留较长主列。直接连接供电的列、已有供电R/L延伸、固定器件及原始导通循环受保护。
3. 只调整没有上游导通宿主的局部列，整列使用同一个行偏移，保留内部先后及间距。
4. 同行证据来自唯一参考管的电流镜、已确认的配对角色，或两条独立串列上至少两种不同控制端的逐级对应。MOS/BJT均使用原D/S、C/E、G/B端口；单纯共G、共时钟、同型号不能产生同行要求。
5. 多输出电流镜的尾源、输出级等角色都提供目标行。当前v2在目标不一致时，比较原行及各合法目标行的快速估价，不再因此直接跳过；同行仅为该多输出镜的布局偏好。参考管不唯一、非电流镜关系冲突、等强起点无明确参照时仍保留原行。
6. 以相同列等级同时提出事务。任何导通先后或已有同行保护被破坏时，撤销所有相关事务，避免按实例名或输入顺序任意选一个。

输入数据、网名、器件、连接、极性和电气层级均不变。G/B关系只用于布局，不增加导通边；没有读取GT坐标、按文件名/编号赋坐标，也没有改动SA/A*权重、选图规则、几何规则或恢复预算。

## 与既有阶段的顺序

```text
原解析、结构识别及电气分层
→ 原R/L/C、V/I显示顺序及核心提取
→ 新对应支路显示行规划
→ 原初排、SA、朝向修正和几何间距检查
→ 原主列、真实引脚对齐与模块插入
→ 兼容的候选3反馈
→ 原A*、完整验收、恢复、选图与安全缩线
```

实际代码路径在骨架中仍是“核心初排与SA→主列及串接对齐→模块插入”；骨架结果原有的反馈保护继续执行。无两端模块的电路使用同一行规划；候选3反馈若携带不兼容的旧行号会被拒绝。SA期间仍固定有源行，不动态插行、移动物理轴或调用A*。

本轮只调整显示起点，没有额外强制“参考管必须在左侧”，也没有实施待修改清单中的MOS朝向优化。C43两条供电列之间的差分对错层仍属于另一类问题。

## 代码与记录

- `netlist2schematic/plugins/columns/branch_rows.py`：证据归并、主列强弱、角色目标一致性及事务检查。
- `plugins/columns/row_estimate.py`：在独立随机状态中构造候选实际初排，复用原SA估价和原RCL/V/I模板、预留空间；不运行SA/A*。
- `plugins/passive_skeleton/candidates.py`：在两端模块插入之前规划核心行，继续原主列和源/无源插入。
- `layout/structured_placement.py`：无模块电路的默认候选2/3接入，保留候选1和关闭模式。
- `flow/aesthetic_flow.py`：阻止不兼容的反馈布局覆盖新行计划。

可选JSON字段`layout_branch_rows`记录版本、原/新行、完整列、依据、受保护列、原导通顺序、已有同行约束、动作、歧义及耗时。`phase: before_sa`明确它记录初排规划，不把原电气层号冒充最终显示行。

## v2：冲突目标行采用代价选择

适用范围是已有唯一参考管、多个输出管给出不同目标行、且至少一个对应主列更强的局部参考列。其他唯一目标行、主列与关闭模式保持原路径。候选仍只有原来的2/3；候选1、旧JSON重布/缩线/重绘均不启用试排。

执行过程：

1. 原行与有证据的目标行一起进入候选集；整列平移，保护供电列、固定成员、导通先后、循环及差分/锁存/堆叠等其他同行约束。
2. 每个候选使用相同种子独立生成真实列位置、朝向、物理坐标与引脚，复用`structured_placement._estimate()`。多输出镜的目标行允许不同，参考管的其他硬约束不放宽。
3. 有两端模块时，复用`make_frame`、`reserve`、`slot_trials`作尺寸及接入投影，将完整端子包围盒、估计折角、朝向回退与拥塞的增量按原SA系数计入。来宾器件的记账行不能产生虚假跨层交叉，交叉估计仍取有源核心。投影不保证合法，真实插入、静态检查和完整布线独立执行。
4. 在合法行中取估价最低且严格改善的方案；与原行同价则保留原行。多个改善方案同价时优先少移动，再相同就保留歧义，不按器件名任意选。存在多个可动列时每轮比较完整状态，提交后重新评估其余列。
5. 最多32次状态估价、0.5秒，消耗原每候选1秒/128次局部预算；不增加SA迭代、整图A*次数或恢复预算。未完成的选择轮次不提交，保留已完成的合法行状态。

`layout_branch_rows.version`为`corresponding-branch-rows-v2`。`target_search`记录各方案行号、初排列/朝向/实际坐标、估价分项、模块投影、选择依据、用时与停止原因；`soft_mirror_rows`明确列出软化的多输出镜同行偏好。原`quality.score`及最终“折角→交叉→线长”选图规则不变。

## v3：汇合处的短输出列也能提供显示行依据

旧v2已经识别多输出电流镜，并能估价多个目标行，但要求至少存在一条更强的对应主列。导通节点发生汇合或对等分叉时，主列算法会保守地将该处输出管保留为单管列；它实际拥有上游主支路，局部列长却与独立参考管相同。因此旧版不会进入估价，参考管仍可能留在整张图最上方。

v3在原 `branch_rows.py` 中补充一种依据，不增加独立后处理或CLI开关：

- 仍须是同极性、同源/发射极、同控制端，且只有一个二极管连接参考管的已确认电流镜。
- 输出列因真实上游导通关系而受保护（`not_a_local_branch_root`），可以提供目标行；不移动这条输出列，也不将汇合处强行拼成主列。
- 仅允许原先可动的独立参考列试排。固定器件、供电列、循环、原导通先后以及其他结构的同行保护仍有效。
- 将原行与所有有证据的目标行交给原有SA快速估价；只提交完整评估后严格改善的方案。同价保留原行，预算不足撤销未完成的一轮。即便目标行唯一，这项新依据也需要经过估价。
- 继续共用32次估价、0.5秒上限及原候选局部预算，不运行SA或A*试摆。网表、电气层级、主列、布线代价及最终选图排序均不变。

默认候选2、3沿用已有 `--column-layout auto` 接入，候选1、关闭模式及保存JSON的重布/缩线/重绘仍保持原路径。JSON版本为 `corresponding-branch-rows-v3`，新增 `junction_mirror_anchors` 记录参考管、输出管及真实上游依据。旧JSON不要求含该字段。

本轮对照与复验记录放在 `output/mirror-reference-rows/`；原成功产物不覆盖。算法不读取GT坐标，不按图号、实例编号或网名指定目标行。
