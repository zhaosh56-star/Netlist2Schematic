# 待改进项

核对日期：2026-11-27。本页是设计积压，不启动后台任务，也不改变默认开关。旧案例截图和手工试摆只能说明当时的问题；修改前应按最新代码、明确网表/cell和同参结果重新确认。

## 仍值得单独研究

- **朝向与真实布线一致性。** 初排和SA已有合法镜像能力，但低成本交叉估计不能覆盖所有同层/跨层交叉。可研究在可信配对上生成朝内／朝外偏好，再验证实际端口与线路；不能只凭共偏置强行配对，也不能破坏串接D/S、C/E轴和G/B端附件。
- **不等长上游支路中的输入对同行。** 识别到差分对不保证两侧原电气层级相同；显示行规划应在SA前协调，同时保持导通先后、固定位置与循环检查。已有[对应短支路齐层](corresponding-branch-rows.md)不等于解决了所有供电列长度差异。
- **有限预算下的复杂附件接入。** 当前已有正常二维择优及失败续插，仍不能保证陌生网表全部成功；应区分位置枚举耗尽、固定冲突和真正的路由超时，再选择改位置、空间或预算。
- **组织与线路取舍。** 默认最终按折角、交叉、线长选择。若要改回结构优先，应作为独立选图决策验证，而不是让某插件暗中覆盖排序。

原c36/c26朝向试验、c43输入对错层的具体坐标、指标及完整建议保留在[2026-11-18待办记录](history/pending-improvements-log.md)。那些案例编号和数值不是本次重新运行的结论；后来的主列、叶块与模块修复可能已经改变其表现。
