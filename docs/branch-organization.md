# 主列与区域前置组织

核对日期：2026-11-27。新网表默认 `--branch-layout auto`，配合 `--column-layout auto`用于结构候选2/3，不以器件数量区分大小图。它是当前支路组织路径；旧 `--region-layout auto` 是另一套默认关闭的实验。

候选2/3的时间与恢复分别计算，见[候选流程](candidate-pipeline.md)。本文不再保留旧共享40%／80%预算说明，历史验证已移至[归档](history/branch-organization-log.md)。

## 它解决什么

逐行独立排序可能把同一支路在不同层排到不同列。先建立可信导通列和局部区域，再运行SA，可以使长主支路连贯、短旁支靠近接入点；区域只在实际占用的行段排序，避免用贯穿整图的大矩形占掉所有空位。

公共偏置、时钟和电源仅作接口，不能单独把不相关支路合并。确认不了完整架构时仍可保留明确的串接、小结构或中性局部区域；没有证据不能记作“零违规”。

## 执行顺序与约束

1. `plugins/columns/column_layout.py`从唯一D/S或C/E续接、可靠复合端口和对应堆栈建立列。歧义分叉保留为接口。
2. `plugins/organization/branch_layout.py`根据端口关系排序局部区域，在各行保持兼容次序；初始化可追加物理列。
3. SA保留原温度与估价器，有限比例动作尝试整列/区域平移或交换；普通动作同样要满足主列和小结构约束。状态拒绝及恢复一起还原位置、朝向和占位。
4. 无源与源件继续通过默认模块预留和插入，辅助布局边不进入真实网络；候选3的反馈必须兼容已保护的计划。
5. 原主列及串接收尾、静态预检、A*、恢复、安全缩线和正式图继续执行。布局阶段不调用A*试摆。

每个器件只有一个区域归属；父块引用小块，不通过共享控制线传递合成巨大刚体。固定器件、有源显示行及合法朝向继续保持。

## 叶块保护与水平交接

2026-11-26补充 `plugins/columns/local_groups.py`：对可信、无歧义的局部叶块，既保护内部不插入无关器件，也保护其原有列跨度。整组平移允许，不能在组内插入多列空白将输入对或镜像拉散。

某些循环邻接里的弱共D/D、C/C连接，在有局部结构依据时可以作为水平交接；真实D/S、C/E串接、跨无源主通道和强核心仍保留原列约束。初排与后续列规整使用同一清单，避免前面保住、后面再次拆散。规则同时作用于MOS和BJT，不按案例编号判断。

## 保存与边界

- `layout_branches`保存版本、依据、接口、覆盖与歧义、动作、前后指标和耗时。
- 先排除违反已提交主列和区域顺序契约的结果，其余合法候选按折角、交叉、信号线长选择，结构软指标和Q不覆盖排序。
- `off`不初始化本插件；候选1、baseline/legacy及不兼容显式实验保持各自路径。
- 保存位置重布、缩线和重绘只按实际坐标重新测量，不重新组织区域。

```powershell
.\.venv\Scripts\python.exe .\run_flow.py .\examples\7.cir --out-dir .\output\7-branches
.\.venv\Scripts\python.exe .\run_flow.py .\examples\7.cir --branch-layout off --out-dir .\output\7-branches-off
# 只看初排，不代表完整布线成功
.\.venv\Scripts\python.exe .\tools\compare_branch_layouts.py --phase preview --cases c04 c20 c21 c22 c24 c33
```
