# 最终选图：折角优先，再看交叉和线长

新网表的结构化候选完成布线和验收后，统一使用 `bends-crossings-wirelength-v1`：

1. 折角更少的候选优先。
2. 折角相同，交叉更少的候选优先。
3. 折角和交叉都相同，信号线长更短的候选优先。
4. 三项完全相同，按稳定的候选编号决定。

这是逐项比较，不是加权相加。例如A为8个折角、4处交叉、线长3000，B为9个折角、0处交叉、线长1000，只要均完整合法，选A。A、B折角同为8时，才先比较交叉；不允许用其他项的改善抵消前一项的劣势。

## 保留与取消的规则

原始引脚连接、同网连通、异网分离、正交性、器件避让、间距及交叉净区继续是硬要求。未完成或未通过验收的线路不能凭借折角少参加比较。

默认支路组织路径还先检查已提交的布局契约：主列断裂、区域穿插、顺序反转或循环顺序冲突的结果不得入选。这是保护已确认结构的资格检查；通过者之间仍按折角、交叉、线长排序，不用结构软评分加权改变先后。

旧115%相对线长门槛、零交叉参考门槛和最多增加1处交叉门槛不再筛选最终候选。主列、结构对齐、附件规整和原综合分Q也不再覆盖上述顺序。因而新规则可能选择线更长或合法交叉更多、但折角更少的图。

这些结构规则仍用于生成布局、保护有源框架和测量结果。Q仍保留原定义，继续用于原有候选3布局反馈和诊断；SA能量、A*代价、几何参数均不改变。旧布局策略的偏好建议仅作为诊断保存。

## 执行时机与范围

默认依次完成候选2、3各自的120秒正常运行、30秒原候选修复、30秒局部救援和30秒扩距重试；某候选成功就跳过它自己的后续恢复，另一个主候选仍继续运行。两者都没有合法结果，才给候选1同样预算；最后才bus。预算和外层720秒保护见[独立候选流程](candidate-pipeline.md)。

默认路径对所有合法候选共用原安全缩线预算，**比较缩线后的实际信号线路指标**。一个候选的失败恢复可以发生在另一个主候选开始之前；未完成、非法或越过硬约束的结果不参与选图。信号线长与报告中包含供电的“全部可见线长”分开。

显式 `--candidate-id` 仍只返回请求编号，不改选其他编号。已有JSON的重绘、固定布局重布和单独缩线不会因为这次改动重新选位置；旧文件保留当时的选图记录。

显式关闭无源模块时，旧候选生成顺序继续保留，最终选择同样采用新顺序；该路径沿用原有选图与后处理时机。可选布局实验仍能改变摆件，但其结构偏好不再覆盖最终选择。

## JSON和代码

`quality.selection_policy` 保存策略版本，`quality.routing_selection` 包含：

- `ranking`：`bends`、`crossings`、`wirelength`。
- `selected_candidate`、`selected_metrics`：实际胜者与比较值。
- `candidates`：按新顺序排列的已验收候选。
- `comparison_stage`：比较发生在共享缩线后，还是原路径布线后。

`quality.score/details` 仍是原Q分数，仅作说明。`quality.layout_preference_diagnostics` 中的 `proposed_candidate` 为旧策略建议，`used_for_selection` 为false，不是实际胜者。

核心实现位于 `netlist2schematic/flow/candidate_selection.py`；`aesthetic_flow.py` 在最终出口统一调用，防止布局插件再次覆盖排序。针对性回归位于 `tests/test_routing_selection.py`。
