# 分步改善电路图可读性

本轮按“平衡缩线 → 无源网络规整 → 源器件归位 → 空隙压紧 → 绕线风险反馈”逐步交付。所有新布局依据源网表拓扑与真实引脚，不读取GT坐标。实验功能先保留关闭开关，最终成品通过对照后再决定默认启用。

本文阶段1～4的数字记录各阶段验收时的代码快照，并非当前修订的全量成绩。后续调整了候选复用范围及弱关系的SA开关，重点输入的早期收益不能代替最新版本回归。当前仍默认`--readability-layout off`及`--route-tradeoff strict`；GT仅用于视觉参考，未完成GT与源网表的全部电气一致性核验。

## 阶段1：少量稀疏交叉换明显缩短

`--route-tradeoff strict|balanced`默认`strict`。`balanced`仍使用原有缩线候选、时间和几何验收，只改变审美取舍：整图相对本次简化开始的交叉净增加最多2处；新增及移动后的交点距其他交点至少为交叉净区的两倍，默认24单位。新增交叉的替换还必须使该路径缩短至少20%，节省至少`max(2S, 150×净增加交叉数)`，折角不增加，且`线长+150×交叉+15×折角`严格下降。`S`取当前物理轴的中位节距。

## 阶段5：有限的真实出口估价和长分支反馈

## 代码与实际执行顺序

| 文件 | 本轮职责 |
| --- | --- |
| `route_tradeoff.py`、`simplify_routes.py` | 原候选生成方法不变，集中判断交叉净额度、交点稀疏和省线收益，记录接受/拒绝理由 |
| `readability_layout.py` | 从原器件端口建立节点锚点、五类无源关系及唯一R/L显示行；无源初排与轻量SA软项 |
| `attachment_placement.py`、`branch_levels.py` | 复用已有合法位置、朝向、并联几何与唯一R/L桥能力，没有开启整个旧结构增强模块 |
| `readability_banks.py` | 依据真实D端出口量测并联负载在哪一侧，证据不足保留未知 |
| `readability_refinement.py` | 无源局部模板、明确源归位和有证据的轴压紧；位置、朝向、占位和物理轴一起提交或撤销 |
| `readability_routing.py` | 仅初排/候选3使用的静态出口风险、实际绕远分支和小支路试摆，不调用A* |
| `readability_selection.py` | 同一关系清单量测全部候选、兼容参照复用、候选门槛和收益选择；保留原quality分数含义 |
| `structured_placement.py`、`aesthetic_flow.py`、`run_flow.py` | 接开关、保持原候选1、组织候选2/3与反馈收尾、恢复、缩线和输出 |
| `tools/compare_readability.py` | 独立目录冻结同参对照、真实候选/来源记录、完整验收、双SVG与保存重绘检查 |

顺序固定为：原解析和识别 → 无源/端口关系及必要R/L显示行 → 原初排或实验初排 → 原SA（强关系增加轻量软项）→ 原朝向/间距修正 → 候选2有条件复用已合法参照、候选3兼容反馈 → 无源/源/压紧共享收尾 → 再检查已接受的出口风险收益 → 静态终检与失败快照 → 原A*及完整验收 → 原质量与组织指标选优 → 必要恢复链 → strict或balanced安全缩线 → 最终验收、JSON和两种SVG。

候选2借用参照时，已生成但未采用的SA状态另存，不称为新SA成果；候选3继续保留独立种子。各后处理都从最新合法坐标起步，后续源/压紧不能掩盖已接受的反馈出口收益。固定布局重布、单独缩线和独立重绘只读取保存的位置并重新量测，不执行这套重新摆件过程。原300秒正常预算、整图A*次数和恢复预算不变；收尾共享1秒/128次，缩线仍默认5秒/512次。
