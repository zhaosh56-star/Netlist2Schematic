# 分步改善电路图可读性

本轮按“平衡缩线 → 无源网络规整 → 源器件归位 → 空隙压紧 → 绕线风险反馈”逐步交付。所有新布局依据源网表拓扑与真实引脚，不读取GT坐标。实验功能先保留关闭开关，最终成品通过对照后再决定默认启用。

本文阶段1～4的数字记录各阶段验收时的代码快照，并非当前修订的全量成绩。后续调整了候选复用范围及弱关系的SA开关，重点输入的早期收益不能代替最新版本回归。当前仍默认`--readability-layout off`及`--route-tradeoff strict`；GT仅用于视觉参考，未完成GT与源网表的全部电气一致性核验。

## 阶段1：少量稀疏交叉换明显缩短

`--route-tradeoff strict|balanced`默认`strict`。`balanced`仍使用原有缩线候选、时间和几何验收，只改变审美取舍：整图相对本次简化开始的交叉净增加最多2处；新增及移动后的交点距其他交点至少为交叉净区的两倍，默认24单位。新增交叉的替换还必须使该路径缩短至少20%，节省至少`max(2S, 150×净增加交叉数)`，折角不增加，且`线长+150×交叉+15×折角`严格下降。`S`取当前物理轴的中位节距。

## 阶段4：占用感知压紧与失效预留带回收

`--readability-phase 4`在附件归位后压紧稀疏物理行列带，并尝试直支路与局部附件联合移列。实际重叠的器件保护区之间保留两条走线通道，反馈明确扩出的通道不压缩；显式固定世界坐标、主动显示行顺序和offset半列边界均保护。每个候选的被动规整、源试摆和压紧共享1秒/128次；所有动作是完整位置/朝向/占位/物理轴事务，失败全部撤销。

当前压紧触发另要求非平凡无源关系、明确串联轴或有源显示行之间实际存在的内部预留带。单独识别出一个局部源只允许该源就近试摆，不授权压缩整套核心；画布边缘留白、源存在或实例名均不足以单独触发全局压紧。

## 阶段5：有限的真实出口估价和长分支反馈

`--readability-phase 5`包含完整可读性流程，`--readability-layout`本身仍默认off。真实引脚到固定出线点之后的两种L形估计会检查halo、标记、异网固定段及端口，信号导线则等待原A*重新构造；估价不代替完整布线验收。

20,000次估价性能对照在图6的17器件真实几何上隔离比较：旧估价约5.35秒，若每次重建场景并附加出口风险约67.47秒，增量远超20%门槛。因此出口风险只用于新候选初排及已有候选3反馈，SA热路径不调用它或A*。初排冻结端对清单、每网最多8对，并按端对规模缩小实算配额；四份真实布局的完整配额约0.17～0.27秒，仍共享原1秒初排上限。

反馈从真实自由分支查绕行，要求长度至少3个节距、至少为两端曼哈顿距离的两倍、绕行余量至少2个节距。它在现有第三候选名额内试相关附件、小叶块换列和合法镜像；共享1秒/128总收尾预算，完全不增加整图A*次数。纯MOS即使没有已识别附件关系也能做几何反馈，未知组织指标保留None；已经识别关系却量测失败时拒绝。
