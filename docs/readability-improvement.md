# 分步改善电路图可读性

本轮按“平衡缩线 → 无源网络规整 → 源器件归位 → 空隙压紧 → 绕线风险反馈”逐步交付。所有新布局依据源网表拓扑与真实引脚，不读取GT坐标。实验功能先保留关闭开关，最终成品通过对照后再决定默认启用。

## 阶段1：少量稀疏交叉换明显缩短

`--route-tradeoff strict|balanced`默认`strict`。`balanced`仍使用原有缩线候选、时间和几何验收，只改变审美取舍：整图相对本次简化开始的交叉净增加最多2处；新增及移动后的交点距其他交点至少为交叉净区的两倍，默认24单位。新增交叉的替换还必须使该路径缩短至少20%，节省至少`max(2S, 150×净增加交叉数)`，折角不增加，且`线长+150×交叉+15×折角`严格下降。`S`取当前物理轴的中位节距。

额度始终相对初始成品计算，不在每次接受后重置。图6的候选可能产生三个新位置交点、同时移除一个旧交点，总数仍只净增两处；稀疏检查覆盖全部新位置。

## 阶段2：无源网络与唯一R/L显示行

增加`--readability-layout auto|off`，默认关闭；`--readability-phase 2`可重放本阶段。它独立识别精确并联组、degree-2串联链、共端点多路径、两臂汇合和单端附件，端点可锚定多端连接节点。候选1保留原算法和随机流，候选2、3使用同一关系清单初排和软评分，继续允许flexible无源微调。明确R/L串链复用原有保守行计划，不改变网表或电气levels。

20,000次提案、正常300秒、原恢复预算及5秒缩线下，四份重点输入off/strict与auto/balanced完整对照全部通过验收及本阶段门槛：

| --- | --- | --- | --- |
| data07 | 904 / 1 / 8 | 962 / 1 / 8 | 两组RLC成组同向；上下供电排列仍有改进空间 |
| data10 | 2184 / 2 / 22 | 相同 | 新摆法虽规整，但真实线长超出115%护栏，保留原候选 |
| data12 | 4366 / 0 / 32 | 3852 / 2 / 26 | 多路径组织与平衡缩线共同改善；交叉增加明确计入 |

这些结果是新布局与balanced缩线的联合成品，不能将所有省线量单独归因于无源初排。记录及图像位于`output/readability-improvement/validation/stage2/`；单独的阶段1对照用于隔离缩线收益。data12的网表与GT有部分连接差异，真实连线始终依据网表。

布局实验与`structure-layout auto`、`symmetry-layout auto`、`region-layout auto`互斥，要求structured/layered及flexible。固定坐标重布、单独缩线和独立重绘只恢复坐标与测量，不执行重新布局。
