# 无源小模块沿连接通道插入

当前构造版本为 `active-first-two-terminal-modules-v4`。普通新网表的结构化、flexible主flow已默认开启 `--passive-skeleton auto`，主列策略仍为 `--column-layout auto`。**只自动运行候选2、3；有合法结果就沿用原规则，两份都失败才修复原骨架，不自动运行候选1。** 比较成品前共用原缩线预算；完整调度、选图、默认值及兼容方式见[候选优先策略](preferred-candidates.md)。显式 `--passive-skeleton off` 恢复原流程。下文v2／v3整批数字保留推广前当时的口径。

v4把有明确两端模块和有源宿主的独立V/I也纳入插入；可与R/C/L共同成组，按实际正负引脚和完整原网表验收。纯供电源、浮空源及归属不明的源保留原核心路径。此扩展只改变显示布局，不修改电气层级；见[源器件模块布局](source-module-layout.md)。

当前正常插入完整通过后，还会执行`normal-module-choice-v1`：保留原合法布局，在候选总截止时间内，给端部附件和跨支路模块比较少量附近位置的机会。所有模块共用最多1秒、64次试摆；主列内的串接模块、成对负载族和固定器件保留原规则。它与失败后的较大二维搜索分开，详见文末“正常阶段的小范围二维择优”。

跨R/L/C支路现补充了导通宿主与控制抽头的区分：两端均有唯一D/S或C/E宿主且方向明确时，先推导显示顺序，再使用原主列和模块预排；单端附件沿原规则完整插入后，补充下文的局部二维找位。C及含C串链标记为仅用于显示布局，不改电气层级。新关系不能抵消旧主列保护，扩距时模块跟随导通宿主。条件与同参实测见[跨无源支路说明](inline-passive-branches.md)。

## 先保有源，再插模块

默认 `--branch-layout auto` 现在在插入前修复真实骨架形状冲突；原快速插入耗尽局部额度时，才在同一候选总截止内追加至多3秒／512案。新网表正常阶段全部失败后，可在原局部救援预算内尝试相关模块换通道，保持有源框架与无关已完成网络。下文1秒／128案描述原共享快速窗口，补试消耗独立记录；固定JSON操作不重新摆件。详见[模块插入与通道恢复](branch-organization.md)。

SA初始化前新增[对应支路齐层](corresponding-branch-rows.md)：较长主列保持，证据明确的局部短列调整显示起点。多输出电流镜有不同目标行时，比较原行及合法目标行的现有SA估价，投影原两端模块的尺寸、端口和预留空间；真实模块插入与静态检查仍在原阶段执行。不改变电气层级或实际连接。

MOS/BJT的主列、上下层次、左右支路和已有小结构是骨架。插入只允许扩大公共行列间隔，不改变骨架成员的逻辑行列或朝向，也不缩放符号。固定器件阻止会移动它的扩距。无源可以使用自由坐标。

每次提交验证真实符号、固定出线、保护区、电源标记和已有模块连接。与所属叶块有明确端口关系的附件可以进入其内部空位；无关器件仍不能插入。最终选图先保护主列连续性与左右顺序，再比较无源规整，不能用无源整齐抵消MOS主列被拆开。

## 模块由拓扑产生

- **串联**：内部节点没有外部抽头的连续连接，沿同一轴按真实连接顺序组合。
- **并联**：具有完全相同两端的路径，分配相邻通道和共同接点。
- **嵌套串并联**：递归组合，例如 `R—(C ∥ (R—L))`；公共的前级R只出现一次。
- **真实抽头**：中间节点接入MOS/BJT、源或其他外部器件时，保留为边界，不跨过它折叠成二端模块。

电源、地和开放端口都是边界。仅共用VDD、偏置或一个信号节点不能把无关支路合成大块。无法归约的桥式网络、多端结构和闭环有明确跳过记录，不任意删节点或漏器件。

所有归约都是布局表达。原始网络、器件、引脚、方向和参数均保留；不真的短接电阻、电容、电感或二极管。唯一R/L关系可以推导显示行；符合相同唯一宿主条件的C、RC、RLC串链也可以建立显示顺序和同列关系，单独标为`capacitive_inline`。电容、反馈及这些显示关系都不会改写原始直流层级。

## 插入与连线

模块尺寸由真实引脚、符号外框、固定出线及分支净区共同计算。串联沿轴展开；并联的子路径有等节距通道、共同的两端母线。先计算完整模块空间，再沿真实宿主端口选择水平或垂直接入通道，空间不足时局部扩距。两端的L形接入都接受原规则检查。

模块内部同时生成普通信号导线。它们没有器件避让或固定段的额外豁免。只有已经连接该网络全部原始引脚、且通过几何检查的完整网络，才作为初始完成网络交给原A*；多端网尚未接完的局部导线不会被冒充为完整网络。其余连接继续由原A*完成，代价、净距和最终独立验收不变。

模块内部连接属于硬检查；宿主到模块的直线/L形属于可丢弃的连接建议。复杂图没有合法L形接入时，不因此直接否定已经安全放下的模块：丢弃该建议，交给真实寻路处理。非法内部线仍会明确失败，建议线也不能成为器件保护区豁免。

v3补齐了复杂图的通道处理。向内的G/B端串联附件与对侧器件、另一侧附件共同计算间隔；只扩公共轴，MOS行列、朝向和主列身份保持。末端负载和跨支路附件从真实器件及供电标记边界产生候选通道，重复障碍不能吃掉不同通道的名额；附近空隙优先，最后保留两个外围通道作为有限后备。扩距之后还会重新停放未处理的临时器件，避免它们的逻辑锚点移动造成假碰撞。

最终布线中，仅当一个涉及模块的网络普通寻路失败时，复用既有 `local_rescue._route_local_net()` 的双端安全接口。每网至多一次、整图不超过 `max_rounds` 次，共用当前候选的原截止时间，不增加独立预算或移动器件；正常成功路线和插件关闭的路径不调用它。接口延长仍是普通线，记录在 `validation.search.module_interface_repairs`，最终继续独立复验全部真实引脚。

这一步没有先运行一次整图A*来画虚拟骨架；使用真实端口和正交通道构造插入关系，最终整图布线次数保持原上限。SA与试摆期间均不调用A*。

## 模块内部紧凑间距（v1）

默认新布局的候选2、3在原模块插入中优先使用紧凑模板；无需新CLI开关。外部宿主接入、MOS/BJT主列、固定器件、原12单位halo、真实引脚出线及A*规则保持原算法。只适用于有明确内部连接的R/C/L/D子模块；V/I接口及串联到复合母线的接口继续保留原空间。单器件模块不消耗一次相同几何的紧凑尝试。

- **串联接头**：对没有外部抽头的相邻两个简单无源件，用实际方向、符号外框及两侧halo计算合法距离。两段同网出线可以共用接头附近的空间，器件、引脚与出线长度不缩放。以当前RC符号为例，中心距80→72，外部两端仍保留原出线余量。
- **并联路径**：依据相邻路径的实际横向包围盒分别计算节距，替代“最大子路径宽度×统一节距”。整体居中，保留两端原母线及出线空间。RLC示例可由原68单位节距收紧至约48～52单位，实际值随路径顺序、方向及符号尺寸计算，不是写死常数。
- **嵌套结构**：递归收紧内部合法子组；不把复合母线与相邻器件强行挤到一起。对子路径宽度不同的模块，反转子路径顺序保持对应镜像几何。

每个紧凑插入仍执行原静态器件/供电标记、固定出线、叶块完整性及模块内部线路检查。几何不合法就从同一个原始骨架重新尝试标准模板，失败试案不残留坐标、走线或扩距。标准模板仍保持原始尺寸计算。

两模板共用原来的单次插入截止时间和试案数：紧凑第一轮最多使用可用时间/名额的75%，剩余额度留给标准回退；提前未用完的时间和名额顺延。不增加SA、最终整图A*次数或恢复总预算。已有失败后3秒/512案的模块插入补试仍独立按原规则触发，每次补试内部也共用自己的原额度。只有剩余额度足够时才实际执行标准回退，预算耗尽仍明确失败。

同一占位状态的静态拒绝缓存跨模板复用；静态合法但内部线路不合法的试案不能借此跳过其他连接建议。紧凑模板只是减少无用留白，不保证所有复杂候选更容易布通，也不保证每个成品的折角均减少。

JSON的`passive_skeleton.module_spacing`保存版本`passive-module-spacing-v1`、实际模板、尝试顺序、分配/消耗额度及停止原因；模块连接中另存局部收紧动作。计划和每组保存实际`spacing_policy`，恢复阶段继续使用对应模板。旧JSON没有这些字段时仍按保存位置与线路复验；旧模块形状度量使用标准模板，不自动重新压紧。开发与测试可将模块计划的`spacing_policy`设为`standard`单独复现原模板，或设为`compact`仅验证紧凑模板。

为保证自定义网格下模板不被撕开，整体平移只对平移量取网格，不分别取整器件中心和各条导线端点。例如电感真实引脚偏移30在4单位网格下仍按真实几何保持，不会被独立取整错开。默认2单位网格下保持原有坐标精度。

实现集中在`module_geometry.py`（相邻尺寸组合）、`placement.py`（原预算内回退及刚性平移）和`plan.py`（按保存模板度量）。GT仅作视觉参照，不进入尺寸计算。原算法、几何规则与输入网表未作放宽或改写。

本轮C07、C23成品及GT对照保存至`output/compact-passive-spacing/`，不覆盖旧图。详细实际结果和回归记录见该目录的`comparison.json`及`regression/`。

## 失败与恢复

每组或对应的两组模块作为完整事务试摆。失败尝试不修改输入骨架，不交付局部接通结果。插入失败时跳过该候选并记录骨架检查点；**不再丢掉骨架，重新运行混合SA**。自动选图保留已经完成验收的参照或其他候选。显式回放某失败候选则报告失败，不能悄悄换图。

后续若进入原扩距恢复，模块整体平移、内部相对坐标保持，清除旧连接缓存后重新布线；逻辑行列、朝向、真实端口均保持。总线后备仍是原有、单独标明的退化阶段。

原来的每候选1秒、128次局部额度及候选数量不增加。已完成的局部连接不等于整图成功；最后仍须检查全部原始引脚和异网分离。

## 端部模块二维找位

默认骨架候选2/3现包含`terminal-module-2d-v1`。它适用于`rail_attachment`、`port_extension`及可独立移动的`terminal_bank`：只有一个服务端，另一端接电源、地或开放端口。服务端可以包含同一信号网上的多个真实端子。R/L/C/D/V/I及其串联、并联、嵌套串并联模块共用此方法。

两个实际宿主之间的中间插入模块继续受原两端/主列通道约束；已确认的成对负载族保留原联合安放，首版不会独立挪动其中一组。固定器件不移动。原归属判定、网表、正负端、器件方向、电气层级及几何规则不变。

执行顺序是：

```text
原对应支路行规划及目标行估价
→ 原核心初排、SA、主列与真实引脚对齐
→ 原模块预留空间及完整插入
→ 全部固定出线、符号/标记和模块内部线通过静态检查
→ 用剩余局部预算作端部二维找位
→ 原A*、恢复链、最终选图与安全缩线
```

二维搜索保留原完整静态合法布局作为基准。围绕真实端口和符号、电源标记边界，优先展开当前试案实际碰到的障碍边界，可同时向上下和左右移动；不再把横纵坐标各自裁成少量最近值，否则复杂空隙中的可用组合可能全部被漏掉。每个模块整体平移，内部相对位置和朝向不变；有源行列、实际坐标、朝向和公共物理轴均保持。

每模块最多生成128个几何状态、保留32个位置、完整检查12个试案。按现有接入线长度优先处理长附件；多端节点的全部真实宿主都参与距离估计。比较局部接入冲突、多端网络的接口余量、明显的有源直连通道受阻风险、专属尾源居中及预计线长/折角/交叉。交叉和折角使用原路由参数的代价。短直连通道只是摆件软估计，不是新增布线禁区，也不会重新启用“信号线不得穿过供电标记”的旧限制。

多端网络尤其需要保留接入余量：两个面对面的固定出口挤得过近，可能静态合法却没有安全树接入点。本策略在位置排序中考虑该风险，保留原主干和短线接入机会，不修改A*或其验收规则。

每份被接受的完整移动重新通过原静态检查、同行叶块保护及全部模块内部连线检查。失败试案撤销，超时保留已检查状态；没有更好的合法位置就保留原插入。这里的原布局仅通过静态检查，信号整图是否可布仍由后续原A*和完整验收确定，不能把静态成功写成最终成功。

设`M`为模块数、`G`为模块中不同器件数，复杂度`K=M+ceil(max(0,G-M)/3)`。没有模块时额度为0，否则使用：

| 复杂度 | 正常阶段补试上限 | 恢复插入上限 |
| --- | --- | --- |
| K≤2 | 3秒／512次 | 10秒／2048次 |
| K=3～5 | 6秒／1536次 | 15秒／4096次 |
| K≥6 | 10秒／3072次 | 20秒／8192次 |

这些是上限，不要求耗尽。正常补试不再与有源整理共用已耗尽的128次；恢复插入最多使用该候选修复份额的60%，原间距与原有1.25倍间距尝试共享同一份时间和次数。所有模块共享计数，父截止时间始终优先，不按模块或倍率重新获得预算。主算法没有因此采用网页的整次300秒限制；总预算仍由调用方和现有调度控制。

`common/layout_budget.py`负责通用额度及共享账本，`plugins/passive_skeleton/packing_budget.py`负责调用原插入和恢复方法。`normal_packing_budget`、`recovery_packing_budget`记录目标额度、实际分配、消耗、剩余及停止原因，区分时间耗尽、次数耗尽和位置枚举完毕。

## 共享节点的接入选择与失败后的短路径接线

2026-11-26的Goal验证进一步定位到两个不同问题，不能都归因于“间距太小”。

1. **可用的宿主被过早锁定。** 一个节点可能同时连接上方管的S/E端与另一只管的G/B端。只有一个导通端，并不表示附件只能靠近这个端口。`owner_port`现在记录`unique_conduction_port`证据；原位置仍先尝试，失败二维搜索可改从同一节点的其他真实端口侧接入，最多四个。明确锁定的归属、公共尾源中点和成对附件族保留原约束，原网络和全部宿主端子都保留。
2. **放得下不等于限定时间内一定能布通。** 失败救援现在对模块接入网先检查一小组直线/L形路径。每次从真实固定出口连接到已有同网树，短路径检查失败才继续原A*救援。该入口不依赖区域识别是否成功，也不修改原始逃逸长度、halo、引脚或交叉净区。

第二项位于`recovery/local_rescue.py`的共用失败入口，实际实现为`plugins/passive_skeleton/module_access.py`。普通首次A*已经成功时不会调用。每个分支最多检查最近8个树接点的两种L形；只有整个网络连通、相关几何检查全部通过才返回，整张图仍需原完整验收。它不是新一轮全局搜索，使用现有救援截止时间。独立重绘继续只读取和复验保存路线。

本轮也修正了规整指标：模块选择加宽模板后，用其实际`extra_keepout`评价形状，不再拿紧凑模板把合法加宽误计为内部错位。

一个未保留的实验是“任何插入成功的附件布局都提前触发模块移动救援”。它会挤占在原位置继续接线的时间。本轮维持原模块移动触发条件和恢复时间分配，只增加失败接线能力。
