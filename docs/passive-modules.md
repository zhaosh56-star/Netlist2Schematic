# 无源小模块沿连接通道插入

当前构造版本为 `active-first-two-terminal-modules-v4`。普通新网表的结构化、flexible主flow已默认开启 `--passive-skeleton auto`，主列策略仍为 `--column-layout auto`。**先运行候选2、3，只有两份都没完成合法结果才运行候选1。** 比较成品前共用原缩线预算；完整调度、选图、默认值及兼容方式见[候选优先策略](preferred-candidates.md)。显式 `--passive-skeleton off` 恢复原流程。下文v2／v3整批数字保留推广前当时的口径。

v4把有明确两端模块和有源宿主的独立V/I也纳入插入；可与R/C/L共同成组，按实际正负引脚和完整原网表验收。纯供电源、浮空源及归属不明的源保留原核心路径。此扩展只改变显示布局，不修改电气层级；见[源器件模块布局](source-module-layout.md)。

跨R/L/C支路现补充了导通宿主与控制抽头的区分：两端均有唯一D/S或C/E宿主且方向明确时，先推导显示顺序，再使用原主列和模块预排；单端附件沿原规则完整插入后，补充下文的局部二维找位。C及含C串链标记为仅用于显示布局，不改电气层级。新关系不能抵消旧主列保护，扩距时模块跟随导通宿主。条件与同参实测见[跨无源支路说明](inline-passive-branches.md)。

## 先保有源，再插模块

SA初始化前新增[对应支路齐层](corresponding-branch-rows.md)：较长主列保持，证据明确的局部短列调整显示起点。多输出电流镜有不同目标行时，比较原行及合法目标行的现有SA估价，投影原两端模块的尺寸、端口和预留空间；真实模块插入与静态检查仍在原阶段执行。不改变电气层级或实际连接。

MOS/BJT的主列、上下层次、左右支路和已有小结构是骨架。插入只允许扩大公共行列间隔，不改变骨架成员的逻辑行列或朝向，也不缩放符号。固定器件阻止会移动它的扩距。无源可以使用自由坐标。

每次提交验证真实符号、固定出线、保护区、电源标记和已有模块连接。与所属叶块有明确端口关系的附件可以进入其内部空位；无关器件仍不能插入。最终选图先保护主列连续性与左右顺序，再比较无源规整，不能用无源整齐抵消MOS主列被拆开。

## 模块由拓扑产生

- **串联**：内部节点没有外部抽头的连续连接，沿同一轴按真实连接顺序组合。
- **并联**：具有完全相同两端的路径，分配相邻通道和共同接点。
- **嵌套串并联**：递归组合，例如 `R—(C ∥ (R—L))`；公共的前级R只出现一次。
- **真实抽头**：中间节点接入MOS/BJT、源或其他外部器件时，保留为边界，不跨过它折叠成二端模块。

电源、地和开放端口都是边界。仅共用VDD、偏置或一个信号节点不能把无关支路合成大块。无法归约的桥式网络、多端结构和闭环有明确跳过记录，不任意删节点或漏器件。

所有归约都是布局表达。原始网络、器件、引脚、方向和参数均保留；不真的短接电阻、电容、电感或二极管。唯一R/L关系可以推导显示行；符合相同唯一宿主条件的C、RC、RLC串链也可以建立显示顺序和同列关系，单独标为`capacitive_inline`。电容、反馈及这些显示关系都不会改写原始直流层级。

## 插入与连线

模块尺寸由真实引脚、符号外框、固定出线及分支净区共同计算。串联沿轴展开；并联的子路径有等节距通道、共同的两端母线。先计算完整模块空间，再沿真实宿主端口选择水平或垂直接入通道，空间不足时局部扩距。两端的L形接入都接受原规则检查。

模块内部同时生成普通信号导线。它们没有器件避让或固定段的额外豁免。只有已经连接该网络全部原始引脚、且通过几何检查的完整网络，才作为初始完成网络交给原A*；多端网尚未接完的局部导线不会被冒充为完整网络。其余连接继续由原A*完成，代价、净距和最终独立验收不变。

模块内部连接属于硬检查；宿主到模块的直线/L形属于可丢弃的连接建议。复杂图没有合法L形接入时，不因此直接否定已经安全放下的模块：丢弃该建议，交给真实寻路处理。非法内部线仍会明确失败，建议线也不能成为器件保护区豁免。

v3补齐了复杂图的通道处理。向内的G/B端串联附件与对侧器件、另一侧附件共同计算间隔；只扩公共轴，MOS行列、朝向和主列身份保持。末端负载和跨支路附件从真实器件及供电标记边界产生候选通道，重复障碍不能吃掉不同通道的名额；附近空隙优先，最后保留两个外围通道作为有限后备。扩距之后还会重新停放未处理的临时器件，避免它们的逻辑锚点移动造成假碰撞。

最终布线中，仅当一个涉及模块的网络普通寻路失败时，复用既有 `local_rescue._route_local_net()` 的双端安全接口。每网至多一次、整图不超过 `max_rounds` 次，共用当前候选的原截止时间，不增加独立预算或移动器件；正常成功路线和插件关闭的路径不调用它。接口延长仍是普通线，记录在 `validation.search.module_interface_repairs`，最终继续独立复验全部真实引脚。

这一步没有先运行一次整图A*来画虚拟骨架；使用真实端口和正交通道构造插入关系，最终整图布线次数保持原上限。SA与试摆期间均不调用A*。

## 失败与恢复

每组或对应的两组模块作为完整事务试摆。失败尝试不修改输入骨架，不交付局部接通结果。插入失败时跳过该候选并记录骨架检查点；**不再丢掉骨架，重新运行混合SA**。自动选图保留已经完成验收的参照或其他候选。显式回放某失败候选则报告失败，不能悄悄换图。

后续若进入原扩距恢复，模块整体平移、内部相对坐标保持，清除旧连接缓存后重新布线；逻辑行列、朝向、真实端口均保持。总线后备仍是原有、单独标明的退化阶段。

原来的每候选1秒、128次局部额度及候选数量不增加。已完成的局部连接不等于整图成功；最后仍须检查全部原始引脚和异网分离。

## 端部模块二维找位

默认骨架候选2/3现包含`terminal-module-2d-v1`。它适用于`rail_attachment`、`port_extension`及可独立移动的`terminal_bank`：只有一个服务端，另一端接电源、地或开放端口。服务端可以包含同一信号网上的多个真实端子。R/L/C/D/V/I及其串联、并联、嵌套串并联模块共用此方法。

两个实际宿主之间的中间插入模块继续受原两端/主列通道约束；已确认的成对负载族保留原联合安放，首版不会独立挪动其中一组。固定器件不移动。原归属判定、网表、正负端、器件方向、电气层级及几何规则不变。

执行顺序是：

```text
原对应支路行规划及目标行估价
→ 原核心初排、SA、主列与真实引脚对齐
→ 原模块预留空间及完整插入
→ 全部固定出线、符号/标记和模块内部线通过静态检查
→ 用剩余局部预算作端部二维找位
→ 原A*、恢复链、最终选图与安全缩线
```

二维搜索保留原完整静态合法布局作为基准。围绕真实端口和符号、电源标记边界，优先展开当前试案实际碰到的障碍边界，可同时向上下和左右移动；不再把横纵坐标各自裁成少量最近值，否则复杂空隙中的可用组合可能全部被漏掉。每个模块整体平移，内部相对位置和朝向不变；有源行列、实际坐标、朝向和公共物理轴均保持。

每模块最多生成128个几何状态、保留32个位置、完整检查12个试案。按现有接入线长度优先处理长附件；多端节点的全部真实宿主都参与距离估计。比较局部接入冲突、多端网络的接口余量、明显的有源直连通道受阻风险、专属尾源居中及预计线长/折角/交叉。交叉和折角使用原路由参数的代价。短直连通道只是摆件软估计，不是新增布线禁区，也不会重新启用“信号线不得穿过供电标记”的旧限制。

多端网络尤其需要保留接入余量：两个面对面的固定出口挤得过近，可能静态合法却没有安全树接入点。本策略在位置排序中考虑该风险，保留原主干和短线接入机会，不修改A*或其验收规则。

每份被接受的完整移动重新通过原静态检查、同行叶块保护及全部模块内部连线检查。失败试案撤销，超时保留已检查状态；没有更好的合法位置就保留原插入。这里的原布局仅通过静态检查，信号整图是否可布仍由后续原A*和完整验收确定，不能把静态成功写成最终成功。

此步骤与原插入合用每候选1秒/128次局部预算的剩余部分，不增加SA/A*次数。`shared_local_budget`的`packing_trials`包含原插入和新增检查；`passive_skeleton.terminal_search`记录版本、试案数、各模块指标、移动前后坐标、超时/停止原因及保留的成对族。原`quality.score`和最终选图规则不变。

之前的目标行估价仍使用原模块模板投影，不会提前运行此二维搜索；保存JSON的重布、缩线和独立重绘不重新摆件。位置、真实引脚、固定出线和电源标记继续统一读取保存的`local_offset`。
