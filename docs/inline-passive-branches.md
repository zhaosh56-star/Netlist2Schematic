# 跨R/L的有源支路：保持同列，不丢控制端抽头

本次修复的是一类通用布局问题：两只MOS/BJT之间夹着R/L，连接节点上还接着G/B控制端。以前这些控制端抽头会让显示行推导放弃该支路，上下器件可能被排到同一层，电阻也被当作普通横向附件。

现在分别记录“导通宿主”和“控制抽头”。例如 `上管D—R—下管D`：上下管决定显示顺序及主列；同节点上的G极仍按原网表连线，不被拉进该列。没有短接R/L，也没有合并原网络。

## 哪些情况会采用

- 无分叉的唯一R/L串链，两端都有明确的MOS D/S或BJT C/E宿主。
- 每端只能有一个导通宿主；可以同时有G/B抽头，包括二极管连接及控制端扇出。
- 中间有外部抽头、两端存在多条导通支路、方向歧义或循环时跳过。
- C、D、反馈和控制端输入链继续使用原附件规则。
- **一端接电源的负载保持原预排**，不因为另端接了G/B就换成新的跨层支路。

只在原本启用无源骨架的结构化候选2、3内生效，无需新增参数。候选1、baseline、legacy及其他显式布局实验保持原路径。`--column-layout off`仍关闭主列规整；已有JSON的重布、缩线和重绘只恢复保存坐标。

## 与原插件的先后关系

```text
原解析、电流层级、结构识别
→ 无源模块计划：同时保留导通宿主和全部控制抽头
→ SA前补齐显示行顺序，复用现有有源层，不把旧无源预留空行变成新有源层
→ 原有源骨架初排及SA
→ 原主列计划加上已确认的跨R/L关系
→ 原主列规整、串接对齐
→ 原无源整组预留、插入与静态验收
→ 原A*、选图、失败恢复、缩线及输出
```

原电气层级数据保持原义。对已确认的接地支路末管，可复用同一地节点其他支路的末行，避免为一只偏置管增加全图空层。这是显示行安排，不改变导通拓扑。

原主列另外保留为保护计划。新关系的规整、R/L后续对齐和模块插入都不能用“改善新列”抵消旧列被拆开、支路顺序翻转或真实引脚偏差增大。控制端扇出只作为原连接和距离估价，不成为刚体归属。候选3继续遵守已插入模块的反馈兼容检查。

如果进入原扩距恢复，模块根据两端导通宿主的位移整体平移，忽略远处控制抽头的位移；内部形状不变，并清除旧走线。最终仍重新执行完整布线与验收。

没有新增SA迭代、整图A*次数、恢复阶段或预算；SA和局部试摆不调用A*。选图仍按折角、交叉、线长排序。
