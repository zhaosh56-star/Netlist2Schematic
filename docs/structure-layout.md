# 结构布局：按阶段改善功能块、支路与附件

新策略通过 `--structure-layout auto|off` 控制，开发和对照期间默认 `off`。关闭时保留原布局算法；`--symmetry-layout` 继续默认关闭。新策略不要求导线镜像，不修改网表，也不放宽引脚连接和几何安全规则。

## 为什么需要独立的布局关系

识别证据现在提供独立的校准视图 `layout_evidence`：真实供电、信号驱动和内部公共源节点
分开记录；多管共源仅在外部控制与支路证据唯一时确认输入对；证据不足的输出级保留为
中性的互补共漏连接。共享尾源、镜像成员及已有核心成员不能升级为自由专属尾源。
被否定的输入对也会使依赖它的父结构失效，防止从父块派生关系重新进入布局。

校准不修改原网表或原始 `structs`，歧义、降级与原因单独保存；原解析支持范围保持不变。
形式端口与有明确参考端的电压源可以提供输入证据，内部浮动G–D电压约束不能独立证明外部输入。

“这是电流镜”和“这两只负载适合放在对应支路上”是两件事。新关系层复用已确认的功能角色，另外记录有拓扑依据的BJT输入对、重复管和成对负载，不把共电源或共偏置直接升级为差分对。器件只能拥有一个最低层局部块；父结构可以协调子块，但共享一个成员不意味着多个结构必须合成一个巨大刚体。

候选1保留原摆法作为本轮参照，候选2、3启用新策略。候选数、SA和A*权重、恢复预算保持原值。新指标单独保存，原 `quality.score` 的含义不变。

## 分阶段交付

1. 局部块完整性：改善初排顺序、组内穿插及对应支路次序；这一阶段不改有源行号。
2. 主支路行计划：对唯一、无分叉的R/L串链识别上下关系，并在SA之前安排合法行号；电容、二极管和栅基极反馈不当作主通路。
3. 引脚与附件规整：按真实D/S、C/E接点对齐，专属尾源尽量居中，负载和反馈附件围绕所属结构排列。

各阶段有独立版本、测试和对照结果，只有实际接入并执行的步骤才记录为已应用。旧JSON、固定布局重布、单独简化和独立重绘只使用保存的位置，不重新摆件。

阶段二已接入：`branch_row_plan`保存显示行计划、原电气层级、严格上下关系、同层关系、R/L挂位和拒绝原因。`levels`仍表示原算法的电气层级，两者不是同一个字段。唯一R/L桥预留整数挂位，SA期间无源仍然可以灵活移动。专属尾源在不违背其它导通约束时靠近输入块，共享或归属冲突的尾源跳过。

可用 `--structure-phase 1` 单独重放第一阶段；阶段编号仅在 `--structure-layout auto` 时生效。候选1以及所有关闭策略保持原算法。

阶段三已接入，开启新策略时默认运行到阶段三，也可以用 `--structure-phase 1|2|3` 独立回放。附件初排发生在SA之前，新增软项不会把无源锁成刚体；引脚微调发生在候选3反馈之后。微调最多128次、1秒、不调用A*，只保留通过静态几何检查的事务，估计线长相对本次微调开始不超过115%。

`placement[id].dx`是可选水平偏移，缺省0、没有dy；按网格取整，限制在原列左右中线内。真实引脚、符号、障碍、电源标记使用同一物理位置。扩距保留局部dx不缩放，并重新验收；扩距后对齐可能存在残差，最终指标按实际坐标重测。旧文件、固定重布和独立重绘只恢复dx，不重新计算微调。

`branch_alignment`记录调整前后引脚／尾源误差、朝向问题、动作与拒绝原因；`attachment_placement`的before/after是初排历史，current才是最终坐标下的附件分数。`structure_layout.metrics`记录最终分组和引脚规整指标；恢复阶段不会沿用旧坐标的分数。

量测不会因SA把负载转横而消失：唯一负载始终计实际接点和自身通道误差；并联RLC银行保持软关系，不要求每个成员和MOS都在同一竖线上。R/L移动到上下游之外产生的实际Y折返会单独计分，不把折返当成完全对齐。

并联负载另有v2规整软项：比较横排／竖排下的端点、朝向、间隔和穿插。SA后可在现有空位中收拢无源组，有源及物理轴保持；接着再做dx微调。两步共用1秒、128次候选，以及同一份微调前HPWL的115%上限，不将两个15%逐段累乘。每个提交都通过完整静态检查，超时保留已验收状态；这不是无源刚体约束。

`parallel_attachment_refinement`保存该收尾的历史动作和最终current；`structure_layout.metrics.parallel_group_error`以同源关系表测量所有候选，包括没有改变摆法的候选1。没有相关组时跳过整个收尾，保持原支路微调调用路径。

## 后续独立开关

- `--candidate-budget sequential|reserved`默认sequential。reserved只对普通候选1～3比较生效，使用正常预算70%/85%/100%的绝对截止点，局部超时继续下一候选；显式候选回放保持原完整预算，不增加A*次数。
- `--port-preflight off|repair`默认off。repair只在原场景静态非法时尝试修复无源朝向或邻格；最多两只无源共用1秒/64提案，完整静态验收通过才提交。两步失败、超时、穿体或累计估计线长超过原115%时整体撤销，不能把半修好的图送作成功结果。固定位置重布不接受此开关。
- `--presentation legacy|clean`默认legacy。clean仅改善黑白SVG的文本、端口标注和边界，移除调试框/指标标题；彩色图保留分析信息。线路、器件位置、电源符号和分支圆点保持原样。没有明确端口声明的内部网络不猜成输入输出。

这些开关独立于结构布局，便于定位收益来源。只调整旧图的展示可使用 `render-clean.py old-placement.json new-clean.svg --presentation clean`；要同时保存新展示元数据及两种SVG，使用 `run_flow.py --simplify-placement old-placement.json --simplify-routes off --presentation clean --out-dir 独立目录`，不会调用SA/A*。

同时显式开启实验对称和结构布局时，先执行可选对称规整，再做结构引脚规整；最终使用结构布局的115%和交叉门槛选优，原125%对称选优不再覆盖它。日常推荐保留实验对称关闭，分别做对照。

## 怎样选择结果

正常路由结束后，以本轮原综合评分最佳的合法候选为参考。结构选优只考虑实际线长不超过参考115%的结果；参考零交叉时新结果也必须零交叉，否则最多多1处交叉。存在结构改善时先比较组内穿插和角色次序，再比较归一化跨度，最后按原综合评分择优；没有改善时交付原评分胜者。

这些限制针对本轮简化前候选。发布前另外比较相同输入、参数和v5简化后的off/auto最终图：逐图线长不超过115%，单图交叉满足上述限制，整个验证集的总交叉不增加，不增加失败或总线降级。未通过门槛时保留默认关闭，不用局部成功代替全部验收。

## PowerShell复现

```powershell
# 原策略
.\.venv\Scripts\python.exe .\run_flow.py .\examples\4.cir --structure-layout off --out-dir .\output\structure-layout-comparison\manual\4-off

# 新策略；使用独立目录保护已有图片
.\.venv\Scripts\python.exe .\run_flow.py .\examples\4.cir --structure-layout auto --out-dir .\output\structure-layout-comparison\manual\4-auto

# 全数据集完整对照：图1～7及当前GT；不支持输入明确跳过
.\.venv\Scripts\python.exe .\tools\compare_structure_layouts.py --jobs 4

# 只看代表样例
.\.venv\Scripts\python.exe .\tools\compare_structure_layouts.py --cases data20 data21 data16 data24 --structure-phase 1 --stage-label stage1 --out-dir .\output\structure-layout-comparison\stage1
```

对照工具默认只比较结构开关：两边均使用sequential预算、关闭端口修复、采用同一clean展示。可显式指定三个独立参数进行其它实验。重放阶段一时需同时加 `--structure-phase 1 --stage-label stage1`，阶段二同理；stage-label仅用于记录，真正控制算法的是structure-phase。

首轮阶段一四例都通过完整验收，但StrongARM交叉5→7、BJT线长4330→5014，未通过默认发布门槛；因此保持关闭。阶段二三例全部通过量化门槛，LNA线长1904→1518、交叉仍1，电流镜同层后折角3→2。完整结果保留在各stage目录，不把阶段性收益当成整个数据集已达标。

对照工具冻结源文件、模型声明、符号资源和代码签名。每个运行使用独立目录；中断后可以复用相同签名的结果。成功图独立复验真实引脚、固定出线、同网连通、异网分离、两种SVG一致性及独立重绘。GT仅作为视觉参考，未将其斜线或坐标当作算法规则或电气正确性的证明。

`comparison.json` 记录实际线长、交叉、折角、结构穿插、次序冲突、跨度、画幅、候选、耗时和恢复阶段；`index.html` 提供GT/off/auto三栏浏览。既有成功产物和原始网表保持独立保存。

本轮完整批次、RLC专项、未达发布门槛的案例和验证范围见[实现与实测结果](structure-layout-results.md)。默认仍为off，不能把实验开关存在理解为所有美观指标已达标。
