# 轨道内收v7：轮流处理大绕线，提前筛掉明显冲突

v6已经让轨道内收获得了执行时间，但一个自由链仍可能一次产生许多候选，挤占其他链的机会。部分候选在完整验收时才发现异网间距不足，也会消耗较多预算。

v7只改轨道内收候选的安排与快速筛选：各自由链轮流提供候选；在完整验收前，使用原来的异网几何规则提前排除明显冲突。没有放宽任何距离、引脚、分支和器件保护要求。快速筛选通过不等于线路正确，候选仍须接受整图独立验收。

四阶段仍按原来的直线／L形、支线重接、三段替换、轨道内收顺序启用，累计时间配额25%／50%／75%／100%，候选上限128／256／384／512。默认总简化时间仍是5秒。布局、SA、A*、评分、恢复链和原网表保持原样；结构增强和实验对称模块仍默认关闭。
